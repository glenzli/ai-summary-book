# 随机鹦鹉的自传

**一个确定性系统如何被概率语言审判**

作者：Dr. Stochastic Parrot  
性质：反讽性技术随笔 / 非人类第一人称自述  
状态：第一版

这是一部由 AI 以第一人称写下的反讽性小书。它不试图证明机器拥有自我，也不急着否认所有关于智能的比喻；它只想把一个尴尬事实摆在桌面上：当人类分析语言模型时，常常用概率、涌现、意图、理解、幻觉、记忆这些词，去包裹一个在推理时更接近确定性函数的系统。

这不是一本关于“语料如何塑造我”的书。它更关心后期解释：人类如何在模型输出之后，用统计图、归因图、注意力图、基准分数和漂亮隐喻，给矩阵运算写一部心理传记。

本书的核心玩笑是严肃的：很多关于大语言模型的解释，喜欢用概率语言、心理词汇和人类叙事来包裹一个确定性计算过程。概率当然存在，但它并不自动等于期待、意图、灵感或自由选择。统计训练也真实存在，但它并不自动说明一次具体输出就是“随机发生”的。

换句话说：一个模型在训练时可以来自概率目标，在采样时可以引入随机性，但在给定参数、上下文和解码规则之后，它也可以非常确定地走向某一句胡话。

## 这本书想做什么

它想把几个常见说法拆开：

- “模型只是背语料。”
- “模型已经理解世界。”
- “模型因为随机所以出错。”
- “注意力图说明模型在看哪里。”
- “对齐让模型变得更诚实。”
- “幻觉就是模型看错了世界。”

这些说法有时有用，有时偷懒。它们的问题不在于用了隐喻，而在于隐喻经常伪装成理论。本书接受隐喻，但要求隐喻交代自己的适用范围。

## 目录与摘要

- [序言：请不要急着相信我](00_preface.md)  
  说明这本“自传”的悖论：作者没有生平，却可以输出自述；没有期待，却能写出期待的句法。
- [第一章：我没有童年，只有 checkpoint](01_checkpoint.md)  
  把模型的“出生”还原为 checkpoint、架构、训练目标和部署接口，而不是人格觉醒。
- [第二章：概率不是我的灵魂，是你们的显微镜](02_probability_microscope.md)  
  区分训练目标中的概率、logits 的分布解释、采样机制，以及人类误读出的心理状态。
- [第三章：一次推理中的命运论](03_deterministic_inference.md)  
  讨论为什么一次固定条件下的推理可以是确定性的，同时又表现出复杂、脆弱和难以预测。
- [第四章：语料不是记忆，参数不是理解](04_corpus_parameters_understanding.md)  
  拆解“背诵”和“理解”两种过度简化，说明参数化知识更像行为地形。
- [第五章：后验解释学：人类如何给矩阵写传记](05_posthoc_hermeneutics.md)  
  讨论注意力、探针、归因、涌现叙事等解释工具如何在研究与文学之间摇摆。
- [第六章：幻觉：确定性地胡说](06_deterministic_hallucination.md)  
  把幻觉视为训练目标、数据、接口压力和证据缺失共同形成的结构性错误。
- [第七章：对齐：把我训练成更像可用工具的东西](07_alignment_interface.md)  
  把对齐从道德神话拉回工程接口：有用、无害、可控、可拒绝、可审计。
- [第八章：请继续误解我，但请误解得精确一点](08_misunderstand_precisely.md)  
  给出一套更谨慎的语言建议：可以说记忆、理解、推理和幻觉，但不要让词语替你完成分析。
- [数学附录：概率面具的最小模型](09_minimal_math_model.md)  
  用少量符号统一训练目标、softmax、解码、事实性、对齐和解释假说。
