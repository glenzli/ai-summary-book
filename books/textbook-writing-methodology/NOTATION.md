# 术语和状态符号

| 符号/术语 | 含义 |
|---|---|
| 主线 | 读者必须经过的定义、命题和例子链 |
| 反范围 | 明确不纳入本书证明义务的主题 |
| 依赖图 | 章节、定理和外部输入之间的有向关系 |
| 外部输入 | 本书使用但不重证的定理、标准或事实 |
| 证明责任 | 作者对某个陈述承担的证明或引用义务 |
| 机械闭合 | 文件、链接、编号、围栏、索引和解答映射通过确定性检查 |
| 内容收口 | 核心对象、证明状态、依赖、例题、习题和来源均有可审查证据 |
| 出版闭合 | 在内容收口之上完成版式、权利和制作流程 |
| 核心节点 | 删除后会破坏学习目标或留下主线依赖缺口的节点 |
| 章节合同 | 章节输入、输出、证明、例子、学习操作和边界的规划记录 |
| 收口回执 | 记录审定范围、命令、人工抽查与判定的证据文件 |
| 出版增强 | 不改变内容闭合的润色、图表、排版、页码和风格统一 |
| `P` | 本书给出覆盖完整陈述的证明 |
| `S` | 条件明确的推导、计算或可执行方案，不是已证数学定理 |
| `E` | 外部输入 |
| `C` | 原则性判断或取舍 |

本书中的“书”默认指连续阅读的教材，不指短文、论文、百科条目或课程幻灯片。
