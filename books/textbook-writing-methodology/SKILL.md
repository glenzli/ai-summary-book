# 教材写作方法论约束

本文件约束 `books/textbook-writing-methodology/` 的写作。

## 1. 对象

本书研究的对象是“教材工程”：

- 领域范围；
- 读者前提；
- 主线依赖；
- 定义与符号；
- 命题和证明责任；
- 外部输入；
- 例题、习题和解答；
- 索引、账本和审计；
- 内容收口。

它不研究市场出版、封面设计、营销文案或排版软件细节。

## 2. 严格性

方法论陈述也必须区分：

- `P`：本书给出论证；
- `S`：本书给出条件明确的推导、计算或可执行方案；
- `E`：依赖外部写作理论、教育研究或本仓库既有标准；
- `C`：原则性判断或审美取舍。

`P` 只用于覆盖完整陈述的书内证明。证明路线附属于 `E`，不能作为独立完成状态；不得把偏好写成定理。凡涉及“必须”“不应”“闭合”等强词，必须给出操作性判据。

## 3. 正文风格

正文以问题和案例推进。每个编号章在第一分节前有自然导言，至少包含一个带编号的完整案例或工作例，以及独立的“练习”分节。案例必须写出输入、操作、观察和结论边界。审计表、模板和清单放入附录或账本，不挤占正文。

## 4. 收口要求

修改后必须检查：

1. 本地 Markdown 链接存在；
2. `THEOREM_INDEX.md` 中编号能在正文找到；
3. 章节练习在 `SOLUTIONS.md` 中有解答；
4. 未出现显式未收口标记；
5. `git diff --check -- books/textbook-writing-methodology` 通过。
6. `CONTENT_CLOSURE_AUDIT.md` 分开报告机械闭合与人工内容闭合，不以文件数量或脚本通过替代内容审读。
