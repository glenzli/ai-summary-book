# 剩余附录稳定 label 表

本文件登记核心附录 A/B/H/K/P/U/X 之外的剩余附录稳定交叉引用 label。它不新增数学内容；用途是把模型范畴、符号、经典例子、Koszul、同伦转移、infinity-operad、factorization、失败模式、案例、前沿接口等附录的可引用目标固定下来。

## 0. Label 规则

**规则 0.1（label 形态）.** 附录 label 采用
`appX-kind-X-NN`
形态，其中 `X` 是附录字母，`kind` 由声明类型决定，编号段由显示编号去点后以 hyphen 连接得到。例如：

- `外部输入定理 G.13` 的基础 label 为 `appG-extthm-G-13`；
- `定义 D.0.1` 的基础 label 为 `appD-def-D-00-01`；
- `命题 Z.5.2` 的基础 label 为 `appZ-prop-Z-05-02`；
- `练习 Y.4` 的基础 label 为 `appY-exercise-Y-04`。

最终排版若需要语义 slug，可在不改变基础 label 的前提下追加 slug。不得把 slug 作为唯一稳定标识。

**规则 0.2（statement type）.** 本表承认以下附录 statement type：

| 类型 | kind |
| --- | --- |
| 定义 | `def` |
| 约定 | `conv` |
| 命题 | `prop` |
| 定理 | `thm` |
| 推论 | `cor` |
| 例 | `ex` |
| 解释 | `exp` |
| 说明、注 | `note` |
| 警告 | `warn` |
| 外部输入定理 | `extthm` |
| 外部输入命题 | `extprop` |
| 外部边界 | `extboundary` |
| 研究边界 | `researchboundary` |
| 反例 | `counterex` |
| 错误命题 | `errprop` |
| 正确边界 | `boundary` |
| 事实 | `fact` |
| 案例 | `case` |
| 问题 | `question` |
| 结论 | `conclusion` |
| 禁止说法 | `forbidden` |
| 模板 | `template` |
| 检查 | `check` |
| 表 | `table` |
| 低阶形状 | `shape` |
| 使用规则 | `rule` |
| 失败模式 | `failure` |
| 练习 | `exercise` |

**规则 0.3（抽取口径）.** 本轮只登记行首形如
`**类型 编号.**` 或 `**类型 编号（...）.**`
的正式编号项，并使用类型白名单排除证明行中的反向引用。

**规则 0.4（与核心附录表的分工）.** 附录 A/B/H/K/P/U/X 已由 [LABEL_LEDGER_CORE_APPENDICES.md](LABEL_LEDGER_CORE_APPENDICES.md) 覆盖；本表只覆盖 C/D/E/F/G/I/J/L/M/N/O/Q/R/S/T/V/W/Y/Z。
