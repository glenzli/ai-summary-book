# 第八至第二十一章稳定 label 表

本文件登记第八至第二十一章的稳定交叉引用 label 规则和正式编号项范围。它不新增数学内容；用途是把 Koszul、bar-cobar、同伦代数、模型范畴、dendroidal、Lurie-style infinity-operad、localization、factorization 和研究边界章节中的可引用目标固定下来。

## 0. Label 规则

**规则 0.1（label 形态）.** 正文 label 采用
`chNN-kind-NN-MM`
形态，其中 `NN` 是两位章号，`kind` 由声明类型决定，`NN-MM` 是把显示编号中的点改写为 hyphen 后得到的编号段。例如：

- `外部输入定理 14.26` 的基础 label 为 `ch14-extthm-14-26`；
- `说明 14.29.1` 的基础 label 为 `ch14-note-14-29-01`；
- `练习 20.3` 的基础 label 为 `ch20-exercise-20-03`。

最终排版若需要语义 slug，可在不改变上述基础 label 的前提下追加 slug，例如 `ch14-extthm-14-26-rectification-criterion`。不得把 slug 作为唯一稳定标识。

**规则 0.2（statement type）.** 本表承认以下正文 statement type：

| 类型 | kind |
| --- | --- |
| 定义 | `def` |
| 约定 | `conv` |
| 解释、展开 | `exp` |
| 设定 | `setup` |
| 公式 | `formula` |
| 命题 | `prop` |
| 定理 | `thm` |
| 推论 | `cor` |
| 引理 | `lem` |
| 例 | `ex` |
| 说明、注 | `note` |
| 警告 | `warn` |
| 外部输入定理 | `extthm` |
| 外部输入命题 | `extprop` |
| 规则 | `rule` |
| 版本表 | `version` |
| 资料 | `source` |
| 待验证问题 | `check` |
| 判定 | `verdict` |
| 流程 | `process` |
| 练习 | `exercise` |

**规则 0.3（抽取口径）.** 本轮只登记行首形如
`**类型 编号.**` 或 `**类型 编号（...）.**`
的正式编号项，并使用类型白名单排除证明行中的反向引用。该口径避免把 `证明.** 由定理 ...` 误登记为 label。

**规则 0.4（编号优先）.** label 绑定到显示编号，而不是绑定到当前 Markdown 行号。后续段落重排不改变 label；若最终自动编号改变显示编号，应另建迁移表。
