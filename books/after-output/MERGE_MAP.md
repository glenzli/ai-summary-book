# 内容融合映射

本表给出七部源书与当前六卷结构的目录级对应。融合不是把摘要并排放置，而是先恢复原书教学正文，再把旧总书独有的审计接口拆入相应章。

| 当前位置 | 主要来源 | 融合结果 |
| --- | --- | --- |
| [导论](00_preface_and_scope.md) | 七部源书与旧总书导论 | 统一对象、证据、判定和控制接口；规定跨卷阅读方式 |
| [卷一](vol-01/) | 《人工智能技术演进综述》、旧总书模型章 | 原导论和六章完整技术史、主要图示、训练记录与模型/系统边界 |
| [卷二](vol-02/) | 《一次输出的存在论》、旧总书输出章 | 原序章和十一章程序语义全稿；旧摘要按对象拆入十个审计接口 |
| [卷三](vol-03/) | 《概率的边界》、《可复现性的幻觉》、旧总书概率/评测章 | 两部课程合为十六章依赖链；保留两套来源、ledger 和解答 |
| [卷四](vol-04/) | 《机器解释学》、《证明、解释与漂亮话》、旧总书解释/验证章 | 两部课程主体共二十四章，另有总览与综合工坊 |
| [卷五](vol-05/) | 旧总书 Agent、伦理、合同与案例章，兼收各源书工程接口 | 六章工程治理和可直接使用的 schema、审计包模板 |
| [卷六](vol-06/) | 《随机鹦鹉的自传》 | 十篇完整重编、原配图、工程翻译表与精确隐喻纪律 |
| [技术附录](appendices/) | AI 数学讲义及六部方法书的严格内核 | 十二篇扩展讲义、C--H 六组证明、反例、协议和解答 |

## Locator 口径

| 前缀 | 责任范围 |
| --- | --- |
| `S` | 总书综合接口、Agent、审计与跨卷案例 |
| `P` | 概率课程原定理与练习 |
| `R` | 复现课程原主张与练习 |
| `M` | 机器解释学原主张与练习 |
| `V` | 验证与论证课程原主张与练习 |
| `C`--`H` | 六个严格证明内核 |

原书的本地数字编号只在卷二内部继续使用；其余前缀保证合章后仍能唯一反查。逐个源章节的位置见 `SOURCE_MIGRATION_MATRIX.md`。
