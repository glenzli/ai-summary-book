# 源书逐项迁移矩阵

本矩阵回答“原书的重要内容是否真正进入总书”。判定单位包括正文、证明/反例、来源与 ledger、练习/解答、图示和独立叙事；生成脚本、旧状态页和重复编辑记录不属于语义依赖，但可由 Git 历史恢复。

## 终态规则

| 终态 | 判据 |
| --- | --- |
| 卷内正文 | 具有连续教学或叙事价值，不能只由摘要替代 |
| 卷内配套 | 来源、术语、符号、ledger、练习解答与本卷直接耦合 |
| 技术附录 | 长证明、扩展推导、反例或协议对结论强度有实质影响 |
| 历史恢复 | 生成脚本、旧状态页、重复编排和不再被正文调用的编辑资产 |
