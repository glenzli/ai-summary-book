# 可审计的人工智能

## 从模型、输出到证据、行动与责任

作者：Dr. Stochastic Parrot

状态：第一版完整在线总书；原工作名《输出之后》。

人工智能教材通常在模型能力处停笔：网络怎样训练，Transformer 怎样生成，后训练怎样塑造回答，Agent 怎样调用工具。本书从这里继续追问：一次能力主张怎样成立，一次运行留下哪些对象，一条事实陈述由什么证据支持，一个结果在什么意义下可复现，一项机制解释能走多远，一次工具行动由谁授权并承担责任。

“可审计”在本书中不是合规口号，而是一项技术性质。若主张、运行、证据和责任之间存在可检查的接口，第三方就能够复核、重放、反驳、降格或追责；若这些接口缺失，再流畅的输出也只是未经闭合的陈述。

本书定位为高年级本科至研究生层次的跨学科 AI 教材，也可作为研究、系统工程和技术治理的参考书。读者宜具备基础线性代数、概率统计和程序执行概念；涉及测度论、因果识别、程序语义或机制解释的深结果会明确标为书内论证或外部输入。本书不是产品排名、编程入门、完整测度论课程，也不提供具体法律意见。

六卷不服从单一文类。卷一采用技术史与概念综述，卷二接近程序语义教材，卷三保持数学课程的定义—命题—证明结构，卷四在实验方法论与科学哲学之间往返，卷五是工程治理手册，卷六则保留机器自传、哲学随笔和精确隐喻的声音。全书要求统一的是对象类型、符号接口、证据边界和交叉引用，而不是句式、章法或习题密度；这种受约束的多声部结构正是总书的组成原则。

## 学习结果

读完本书，读者应能：

1. 区分模型工件、部署系统、运行轨迹、显示文本、持久制品和现实副作用；
2. 把概率、校准、复现和能力评测绑定到明确的对象、分布、协议和比较关系；
3. 为注意力、探针、干预、电路和稀疏特征提出与证据强度相称的解释主张；
4. 区分答案正确、理由有效、证书通过、过程忠实和来源支持；
5. 为 Agent 工具调用设计权限、审批、幂等、日志、回滚和责任链；
6. 将一次高风险 AI 运行整理为可独立复查的审计包。

## 阅读路线

总书采用“卷目录/章文件”结构。每卷的 `README.md` 给出卷内顺序、详细章与综合章的关系以及卷内配套材料；根目录只保存全书入口和跨卷资料。

1. [卷一：模型、训练与系统](vol-01/)：AI 技术演进、深度学习、Transformer、预训练、后训练、多模态、Agent、世界模型，以及模型工件与部署系统的审计接口。
2. [卷二：输出对象与运行语义](vol-02/)：字节、Unicode、token、偏函数、状态、轨迹、概率生成、工具、副作用、并发、provenance、真值与责任。
3. [卷三：概率、复现与评测](vol-03/)：测度概率、条件信息、收敛、评分、校准、随机算法、因果、数值复现、统计复制、复现合同与能力决策。
4. [卷四：解释、证明与验证](vol-04/)：行为证据、归因、注意力、探针、patching、电路、SAE、逻辑有效性、数学解释、科学证据、引用、CoT 与验证协议。
5. [卷五：Agent、治理与审计包](vol-05/)：运行时、权限、审批、未知提交、补偿、责任链、记录 schema、审计模板和端到端案例。
6. [卷六：机器叙事与精确隐喻](vol-06/)：完整保留并重编《随机鹦鹉的自传》的技术随笔、数学模型与工程翻译。
7. [证明与技术附录](appendices/)：学习、概率、运行语义、数值复现、可解释性与验证逻辑的证明内核，以及较长的学习理论讲义。
