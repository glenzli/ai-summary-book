# 《可复现性的幻觉》习题解答

解答保留正文中的对象类型、假设与三值边界。计算题给出足以复核的中间步骤；方法题
明确说明结论只覆盖哪一层复现，避免用答案中的简写越过正文合同。

## 序章

**练习 R0.1.** 设对象都是同一测试集上的两个分类模型。第一份合同令 $N$ 读取权重文件规范字节，要求字节身份；第二份令 $N$ 计算逐样本概率向量，先用资格谓词检查形状与特殊值，再由 $M$ 使用混合绝对/相对容差；第三份把独立训练运行作为实验单位，$M$ 比较平均准确率差的预定等效区间。第一份是精确等价，第二份一般是非传递接受关系，第三份是带错误率的统计判决。

**练习 R0.2.** 原研究含标签泄漏。第二次运行复制同一数据、代码和环境，输出逐位相同；独立团队在无泄漏的新数据上看不到效应。逐位合同的对象是计算字节，科学复制的对象是无泄漏总体上的效应，二者一成一败不矛盾。

**练习 R0.3.** 两个数值积分实现使用不同约简树，最低位不同；两者各有误差界，且守恒量误差均在预定物理容限内。字节身份失败，数值和科学主张仍可通过。

**练习 R0.4.** 例：$\mathcal D$ 是含十个配对槽位且 schema 合法的训练清单；每个槽位含成功记录、明文失败记录或缺失标记。$N$ 读取可用的配对准确率差与状态；$P$ 检查数据版本、配对块、失败清单是否完整且十对有效差均存在；$M$ 指定独立同分布正态配对差模型与 $0.005$ 门槛；$A$ 按第 11.7 节单侧界返回三值。合法清单中的缺失/失败使 $P=0$ 并按本合同返回 `INCONCLUSIVE`；schema 损坏则是 `schema_error`；区间跨门槛也返回 `INCONCLUSIVE`。

## 第一章

**练习 R1.1.** 取 $0,3\varepsilon/4,3\varepsilon/2$，相邻距离均不超过 $\varepsilon$，首尾距离超过，故 $\varepsilon>0$ 时不传递。若 $\varepsilon=0$，关系化为实数相等，是等价关系。

**练习 R1.2.** 字节串 `{"a":1,"b":2}` 与 `{ "b": 2, "a": 1 }` 不同。令解析函数把合法 JSON 映到键到数值的有限映射；忽略对象成员顺序后，两者解析值相等。若合同把原始格式或重复键处理视为语义，必须进一步限制合法域。

**练习 R1.3.** 标签身份令 $L(r)$ 为有限标签序列，并比较 $L(r)=L(r')$，是核等价。概率容差令逐元素最大差不超过 $\varepsilon>0$，一般不传递。总体性能合同以独立训练运行样本计算区间并返回三值，不是等价关系。

**练习 R1.4.** 抗碰撞摘要匹配使规范字节不同而摘要相同在工程上极难构造，但有限摘要数学上必有碰撞。即使字节真的相同，攻击者也可复制该内容；作者身份、签发时间和传输链仍需签名或可信日志。

**练习 R1.5.** 归并排序和堆排序的比较/交换轨迹不同，但最终都输出同一已排序序列。若轨迹投影包含终止数组，令 $h$ 取投影轨迹最后一个数组，则投影轨迹身份推出输出值身份；输出值身份不推出轨迹身份。

## 第二章

**练习 R2.1.** 具体状态可含待洗牌数组、当前排列、游标、PRNG 当前状态和输出缓冲；外生事件含文件读取、时钟或调度。观察可选最终标签、最终权重字节或逐步 batch 轨迹。只记录最终排列可能对最终 batch 集合充分，却不对随机字消费轨迹充分；完整具体状态加同一外生流对三者都充分。

**练习 R2.2.** 确定但不幂等：$f:\mathbb N\to\mathbb N$，$f(n)=n+1$。幂等但有副作用：操作 `set-file-to-fixed-bytes`，第二次执行不再改变文件。纯且幂等：$g:\text{List}(\mathbb Z)\to\text{List}(\mathbb Z)$ 把列表排序并去重；输出仍在同一类型中，故 $g(g(x))=g(x)$ 有类型。

**练习 R2.3.** 候选项包括模型/缓冲/梯度累积、优化器、scheduler、梯度缩放器、全部 RNG 当前状态、数据排列与游标、rank 映射、通信状态、step、早停和选择状态。清单只是候选：还需证明相同记录加相同未来事件足以决定目标观察，或在明确有限域内验证该性质；遗漏的隐藏状态仍可能构成反例。以数据游标为例，取两个具体状态使其他记录分量相同、游标分别指向 batch A 与 B；给二者同一未来调度/文件响应，下一步 batch ID 观察不同。正文标量例中，两状态都记录 $w=1$，游标却分别指向目标 $0$ 与 $2$；学习率为 $1$ 时下一步参数分别为 $0$ 与 $2$。这是游标分量的删项区分见证，只证明删除游标后的当前记录不充分；它不证明完整清单已经充分，也不证明游标信息不能由“下一样本 ID”等另一字段替代。

**练习 R2.4.** 程序 A 从 $0$ 连续加一两次，程序 B 直接赋值 $2$；两者只记录最终值 `2`。日志映射把不同内部轨迹映到同一字符串，因此非单射，日志相同不推出轨迹相同。

**练习 R2.5.** 所有 worker 使用同一 seed 可产生相同 augmentation，破坏样本间预期独立性。若随机数按到达次序从共享流分配，改变 worker 数会改变任务到随机字的映射；即使主 seed 不变，逻辑样本的随机变换也会改变。应使用版本化子流派生并保存映射。

## 第三章

**练习 R3.1.** 在三位十进制有效数字、指数范围足够且舍入到最近的系统中，取 $a=1.00\times10^4$、$b=-1.00\times10^4$、$c=1.00$。左侧先得 $a+b=0$，再得 $1.00$。右侧精确 $b+c=-9999$，最近三位数是 $-1.00\times10^4$（距 1，另一邻点 $-9.99\times10^3$ 距 9），故右侧为 $0$。

**练习 R3.2.** 在 $(k+1)u<1$ 时，

$$
\gamma_{k+1}-\gamma_k
=\frac{u}{(1-ku)(1-(k+1)u)}>0.
$$

又令 $x=ku\to0$，则 $\gamma_k=x/(1-x)=x+x^2+O(x^3)$，故一阶为 $ku$。

**练习 R3.3.** 定理 R3.5 两边除以 $|s|$ 得

$$
\frac{|\widehat s-s|}{|s|}
\le\gamma_{n-1}\frac{\sum_i|x_i|}{|s|}
=\gamma_{n-1}\kappa_{\mathrm{sum}}.
$$

$s=0$ 时相对误差分母为零，$\kappa_{\mathrm{sum}}$ 不定义为有限数；应保留绝对误差界或使用问题特定尺度。

**练习 R3.4.** 先比较形状、单位和 dtype；不匹配则 `FAIL`。规定 NaN 只在双方同位置出现才通过该位置，正负无穷必须同号，正负零按数值或字节规则明定。其余有限元素要求

$$
|a-b|\le10^{-12}+10^{-8}\max(|a|,|b|).
$$

所有元素通过才 `PASS`；字节不满足输入 schema 或无法按声明格式解析时返回 `schema_error`，而格式合法但制品以明文缺失标记表示不可访问时可返回 `INCONCLUSIVE`。阈值还需由实际误差/决策预算校准。

**练习 R3.5.** 顺序求和逐位合同固定输入序列和每一步格式；平衡求和固定补零和树；补偿求和固定补偿变量更新、FMA/重结合和编译语义。数值合同可分别用定理 R3.5、命题 R3.6 或经引用证明的补偿界。三算法之间通常只比较数值，不比较字节；补偿算法的更准确结果也不必复现原顺序字节。

## 第四章

**练习 R4.1.** 记每线程链为 $R_i<C_i<W_i$。满足“两读均早于任一写”的 18 个线性扩张分四组：

```text
R1 C1 R2 C2 W1 W2    R1 C1 R2 C2 W2 W1    R1 C1 R2 W1 C2 W2
R1 R2 C1 W1 C2 W2    R1 R2 C1 C2 W1 W2    R1 R2 C1 C2 W2 W1
R1 R2 C2 W2 C1 W1    R1 R2 C2 C1 W2 W1    R1 R2 C2 C1 W1 W2
R2 C2 R1 C1 W2 W1    R2 C2 R1 C1 W1 W2    R2 C2 R1 W2 C1 W1
R2 R1 C2 W2 C1 W1    R2 R1 C2 C1 W2 W1    R2 R1 C2 C1 W1 W2
R2 R1 C1 W1 C2 W2    R2 R1 C1 C2 W1 W2    R2 R1 C1 C2 W2 W1
```

每次读取都得到 $0$，两个局部计算均为 $1$，两次写入无论顺序都写 $1$，终值故为 $1$。

**练习 R4.2.** 用 $a=2^{54},b=-2^{54},c=1/2$ 做三个原子加。到达次序 $a,b,c$ 得 $(a+b)+c=1/2$；次序 $b,c,a$ 得 $(b+c)+a=0$。原子性保证每次读改写不可分并进入某一串行顺序，不保证该顺序唯一。

**练习 R4.3.** 状态：各 rank RNG 当前状态、数据游标、通信缓冲。外生事件：worker 到达、故障/重试、网络完成顺序。算法配置：rank--数据分片、每 rank batch、通信桶、all-reduce 树、归一化策略、学习率缩放。实际系统中某项可同时通过配置决定状态布局，应在具体模型中定型。

**练习 R4.4.** 不变量：每个全局样本 ID 只属于一个已提交 step，且该 step 的参数更新和数据 offset 要么都可见，要么都不可见。checkpoint 必须包含向下闭合的因果前缀；若记录接收/更新却没有其发送或输入消费，恢复状态不对应合法全局历史；若发送已在割内而接收未在割内，还要保存该在途消息。可用同一事务，或带 step ID 的幂等更新、offset 与通道状态实现。

**练习 R4.5.** 固定初始沙箱、规范请求、逻辑调用 ID、请求偏序和每个 ID 的响应字节；调度若影响程序，则保存线性扩张或证明不可比调用交换。replay 只验证这些响应下的控制逻辑；实时服务版本、延迟和内容漂移另设 live 合同。

## 第五章

**练习 R5.1.** 显式随机变量：初始化、shuffle、augmentation、dropout 和随机采样。调度非确定性：worker 到达、GPU 原子顺序、autotuning/通信选择。确定派生分支：在给定数值轨迹下，梯度缩放器检测 overflow 后跳过更新。该分支可因前两类差异而在运行间不同，但本身不是独立随机源。

**练习 R5.2.** 固定训练模型 $j$ 后，对测试样本重采样主要估计 $\varepsilon_{a,j,k}$ 聚合的不确定性；只有一个 $j$ 时没有训练运行样本来识别 $U_{a,j}$ 的方差。若目标量明确是“这个固定模型在测试总体上的性能”，测试 bootstrap 仍可有用。

**练习 R5.3.** 先抽取独立块 $j=1,\ldots,n$。每块固定同一 split 和预算，共享可比的数据扰动设计；A、B 的参数初始化子流按明文映射生成，必要时独立。分析单位是块差 $D_j$，报告所有 $D_j$、均值和预定区间。相同 seed 整数不替代该映射。

**练习 R5.4.** 令 $V_1,V_2$ 独立且各以一半概率取 $0.78,0.82$。每个期望为 $0.80$，而最大值仅在二者都低时为 $0.78$，其余为 $0.82$，故期望为 $0.25(0.78)+0.75(0.82)=0.81$。命题 R5.2 只给非严格不等式；若 $V_1=V_2$ 几乎处处，则等号成立。

**练习 R5.5.** 配置复现需最终配置、数据、实现和评测；轨迹复现再需完整状态、事件流和固定数值/调度；统计复现需独立运行设计、目标量和判决；方法复现还需搜索空间、预算、失败与选择规则。同一机箱或相同文件名可能便利但非必要；独立实现也可满足统计/方法目标。

## 第六章

**练习 R6.1.** 取 logits $\ell=(0,-m)$，扰动 $e=(-q,q)$。若 $q<m/2$，新间隔 $m-2q>0$，第一 token 不变；若 $q>m/2$，第二 token 反超。正文数值取 $m=2\times10^{-7}$：$q=0.9\times10^{-7}$ 时新间隔仍为 $0.2\times10^{-7}$，$q=1.1\times10^{-7}$ 时新间隔为 $-0.2\times10^{-7}$ 并翻转。超过 $m/2$ 不必改变 argmax，例如扰动 $(q,q)$ 保持间隔，所以命题给的是充分条件。

**练习 R6.2.** 充分条件包括模型/logits、排序、top-$p$ 边界、PRNG 算法和当前状态、消费顺序、批处理、停止规则与环境相同。反例：两序列共享随机流，动态批中序列 A 提前停止，序列 B 随后消费到不同随机字；主 seed 相同但 B 的 token 轨迹改变。

**练习 R6.3.** 交叉单请求/固定批/动态批，短/长上下文，普通/近并列 margin，cache miss/hit 和低/高负载。逐格报告字节、token、logprob 范数、任务标签和延迟；字节是精确观察，logprob 是容差观察，重复动态负载形成统计观察。

**练习 R6.4.** replay 中搜索响应被冻结，故可验证模型在给定证据下是否调用正确工具；live 中搜索索引变化，验证部署整体。模型控制逻辑可在 replay 通过，而 live 因 API schema 变化失败；反之，replay 的旧响应损坏可失败，而 live 当前服务正常。

**练习 R6.5.** 预先固定有限提示集、时间窗、重复数、评分器、版本记录和三值阈值。全部通过只允许说“在该有限哨兵集和采样设计上未检测到超合同漂移”；不能说后端权重相同、所有输入行为相同或未来不会漂移。

## 第七章

**练习 R7.1.** 两合同都固定 UTF-8、LF、列名/类型、缺失值和数字格式。行序有语义时按原序编码；无语义时先按能唯一标识记录的规范键排序，并规定重复键次序。schema 作为清单字段参与规范编码，否则相同 CSV 字节可被解释成不同单位或类型。

**练习 R7.2.** 取 Entity 节点：网页响应边界 $E_0$、原始分片 $E_1$、标签版本
$E_2$、清洗代码 $E_3$、split 配置 $E_4$、清洗后数据 $E_5$、训练 split $E_5'$、
容器 $E_6$ 和 checkpoint $E_7$；Activity 节点：获取 $A_1$、清洗/标注 $A_2$、
split $A_3$ 和训练 $A_4$；
Agent 节点：数据提供者 $G_1$、标注团队 $G_2$、运行团队 $G_3$。使用/生成边可取

$$
E_0\to A_1\to E_1,
\qquad
(E_1,E_2,E_3)\to A_2\to E_5,
\qquad
(E_5,E_4)\to A_3\to E_5',
\qquad
(E_5',E_6)\to A_4\to E_7,
$$

其中括号表示每个列出的 Entity 都有一条指向该 Activity 的
$E_{\mathrm{use}}$ 边；Activity 到输出 Entity 的箭头属于 $E_{\mathrm{gen}}$。责任关联
边取 $G_1\to A_1$、$G_2\to A_2$、$G_3\to A_3$ 和 $G_3\to A_4$，均属于
$E_{\mathrm{assoc}}$。把无法归档的网页响应 $E_0$ 记录时间与摘要，并列入
$B_{\mathcal M}$ 的不可追溯边界。若 $\mathcal M$ 声明的全部影响输入就是上述节点，
则从 $E_7$ 反向追踪的计算谱系闭合；每个活动也都有 Agent 关联，故责任关联闭合。
这两个结论都相对于 $\mathcal M$，不证明网页内容真实，也不证明各 Agent 的责任声明
已经独立核验。

**练习 R7.3.** GPU 型号、驱动、宿主内核、微码、网络拓扑、挂载数据、时钟和资源限制都可在镜像外。设 $\mathcal X$ 含这些具体执行描述，$Q(x)$ 只保留镜像清单，$O(x)$ 是合同选择的数值输出。命题 R7.7 要求存在唯一 $h:\operatorname{im}(Q)\to\mathcal Y$ 使 $O=h\circ Q$。若同一镜像配不同驱动或挂载数据可给出不同 $O$，便得到 $Q(x)=Q(x')$ 而 $O(x)\ne O(x')$，故因子分解不存在、镜像不充分；反之，不同镜像可能在有限合同域上实现同一 $O$，所以镜像相同也不是无条件必要条件。

**练习 R7.4.** 若 $c(a)=c(b)$，对函数 $H$ 两边应用即得 $H(c(a))=H(c(b))$。逻辑逆向要求 $H$ 在相关域单射；工程上则可把抗碰撞性作为明确的计算安全假设，但不能把它改写成单射定理。签名验证只直接说明给定签名、消息与公钥满足验证算法；在签名方案安全和私钥控制等假设下，它才支持“持钥者签发且消息未被替换”的归因。它仍不证明算法正确，也不凭空证明公钥对应的现实身份。

**练习 R7.5.** 可把分析容器送入受控数据环境，由可信第三方核对原数据摘要、运行合同并签发报告；公开 schema、变换代码、合成数据和非泄露统计。公众可验证代码可运行、报告签名和公开部分；只有受权第三方能验证原始记录及其与摘要的对应。缺第三方访问时，原数据上的独立复核应标 `INCONCLUSIVE`。

## 第八章

**练习 R8.1.** 同一团队在同一测量程序、系统和运行条件下重复计算，按 ACM 是 Repeatability。若未说明它使用原数据/代码还是新收集数据，NASEM 不能仅凭“同设置”判断是 computational reproducibility 还是 replicability。

**练习 R8.2.** Results Reproduced：独立团队至少部分使用作者制品获得主要结果。Results Replicated：独立团队不使用作者制品而独立获得主要结果。Artifacts Available：制品置于可长期检索公开归档。Artifacts Evaluated--Functional：独立审计确认文档、相关性、完整性和可执行性等功能要求。四者不是同一徽章。

**练习 R8.3.** 改变地点、操作者和测量系统；保持被测量定义、样品批次或相似对象规则、校准链、环境容限和分析程序。报告各实验室重复测量及 reproducibility conditions 下的离散量，并明确不同系统是否采用不同程序。

**练习 R8.4.** 两研究都显著可方向相反或效应量差异巨大。边际区间是否重叠不使用两估计量协方差，也不直接检验它们的差或等效性；应对目标差构造相应检验/区间。

**练习 R8.5.** “按 NASEM（2019）的 computational reproducibility 口径，团队 B 使用归档数据、代码和分析条件重算表 2；两个水平 $0.05$ 的单侧等效检验均拒绝，其对应的 $90\%$ 双侧置信区间严格位于预定 $(-0.02,0.02)$ 内。”

## 第九章

**练习 R9.1.** 取 $\widehat\psi=0$、$s=0.2$。双侧正态 $p=1$，$95\%$ 区间约为 $[-0.392,0.392]$，不包含于 $(-0.2,0.2)$，故没有等效证据。

**练习 R9.2.** 两个单侧检验各取 $\alpha=0.05$ 时，对定理 R9.3 的连续对称枢轴对应 $100(1-0.10)\%=90\%$ 双侧区间。若用 $95\%$ 区间并要求其落入等效界，则得到更保守的充分条件；它不与标准水平 $0.05$ TOST 等价。正文的 $\widehat\psi=0.0065$、$s=0.002$ 正好给出对照：$90\%$ 区间上端约为 $0.0097897$，落在 $0.01$ 内；$95\%$ 区间上端约为 $0.0104199$，越过同一边界。

**练习 R9.3.** 方向相同不要求精度；“都显著”分别比较零点，甚至可在编码方向不一致时误读；TOST 直接比较目标差与实质界，但依赖界和模型。TOST 可通过而各研究对零不显著；两个研究也可各自显著却彼此差异超过等效界。因此无无条件全序。

**练习 R9.4.** 增加测试样本减少固定模型条件下的评测误差，不能识别训练运行效应 $U_{a,j}$ 的方差。配对目标为 $\mu_D=\mathbb E[M_{A,j}-M_{B,j}]$，样本单位是独立实验块的 $D_j$。

**练习 R9.5.** 设整族错误率目标为 $\alpha=0.05$。可对每个基准构造水平 $\alpha/5=0.01$ 的 TOST；在定理 R9.3 条件下，每项使用 $98\%$ 双侧区间并要求落入各自等效界。Bonferroni 保证错误宣称至少一个等效的概率不超过 $0.05$。BH 控制的是错误发现比例的期望，通常更有力但需要相应依赖假设，目标不同。

## 第十章

**练习 R10.1.** 保存 step 0、417 及中间可对齐 checkpoint 的具体状态/事件摘要，先二分最小不同 step，再在该 step 内按层和算子细分。反例一：低位差异在后续舍入中消失，使“前缀输出是否不同”先假后真；反例二：动态调度使两运行 checkpoint 的事件集合不对齐。此时需事件 ID 对齐或记录调度，不能直接二分索引。

**练习 R10.2.** 合理：标准误差分析表明允许约简树的最坏误差为 $10^{-7}$，旧阈值 $10^{-9}$ 与合同的跨设备目标矛盾；发布新合同版本并把旧结果标为事后重评。不合理：看到当前差值 $3.2\times10^{-5}$ 后把阈值改为 $3.3\times10^{-5}$，没有独立误差或决策依据。

**练习 R10.3.** 降低线程数会改变事件偏序、缓存压力和原子到达顺序，竞态可能消失。替代诊断是保持原并发度和数据规模，加入调度记录/重放、竞争检测和失败注入，只缩减与触发条件无关的输入内容。

**练习 R10.4.** “在合同 C-17、相同记录输入和 seed 下，动态批模式的 20 次运行有 7 次从 step 417 的 layer 23 起最大绝对差超过 $10^{-5}$；固定批 20 次未出现。已观察的竞争解释是核选择与请求调度，尚无证据区分二者。”

**练习 R10.5.** 抽样波动：扩大预注册样本后区间按模型缩窄；总体变化：按总体协变量分层后效应系统变化；实现差异：在同数据上交换实现重现差异；原研究选择偏差：取得完整候选结果后公开效应回落；测量变化：用共同校准对象能解释偏移。每项都给出不同的可检验预测。

## 第十一章

**练习 R11.1.** $\mathcal D$ 是含方程、网格、初值、扰动流和求解器配置的合法有限清单；$N$ 解析终态与收敛日志；$P$ 检查单位、网格、运行终止和参考解可访问；$M$ 规定状态范数、守恒误差、随机重复与区间；$A$ 三值判决。NaN 或未收敛按合同为 `FAIL`（若其违反算法主张）或 `INCONCLUSIVE`（若资源中断）；空输出属 schema 错误。十项字段再记录环境、随机状态、谱系和失败处理。

**练习 R11.2.** 新增固定数据顺序、全部 RNG 当前状态、设备/驱动、内核、FMA/舍入、约简树、线程/调度、checkpoint 序列化与非语义元数据。它们在固定实现模型中可构成充分条件。相同物理 GPU 未必必要，因为另一设备可能实现相同字节函数；相同容器也未必必要，因为不同镜像可含字节相同的相关运行组件。

**练习 R11.3.** 采用受控访问环境：第三方验证原数据摘要、执行容器、输出清单并签名；公开 schema、代码和合成数据。合同规定若第三方报告、签名或访问审计缺失，原数据结果为 `INCONCLUSIVE`，而公开合成数据上的功能测试可独立判决。

**练习 R11.4.** 有限测试只计算 $f(x_i)=g(x_i)$，$i=1,\ldots,n$。定理 R11.4 排除一般的全自然数输入等价判定。允许声明：“两个版本在版本化测试集 T 的全部 10,000 个输入上输出字节相同”；不允许据此声明“两个程序对所有输入等价”。

**练习 R11.5.** 域：未给可运行输入与数据 schema；状态：源码不固定依赖、RNG、硬件和服务；统计：未给实验单位、重复数和判决；谱系：仓库分支不保证不可变，也未证明发布二进制来自源码；可判定性：“完全”可能量化所有环境/输入。故开源只支持代码可访问，不足以推出任何未定义的完整复现。
