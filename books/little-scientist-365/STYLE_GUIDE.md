# 《小小发现家》写作与插图约束

本文件约束《小小发现家：365 天，每天一个为什么》的正文、互动和插图。目标读者是约 4 岁的孩子，实际使用者通常是陪读的大人。

## 文字

1. 每天只讲一个核心事实。标题必须是孩子可能提出的问题。
2. 每页采用两层解释。第一层用 3--5 个短句直接回答；第二层以“再想一步”补充 2--4 句科学原理。完整朗读约一至两分钟。
3. 先说可观察的现象，再展开一条清楚的因果链。必须使用术语时，立刻用普通话解释，并说明这个术语解决了什么问题。
4. 可以使用比喻，但不能把比喻冒充事实。动物、云、机器不被写成真的会思考或故意行动。
5. 不使用“永远”“所有”“一定”等容易制造错误例外的绝对表述。
6. 不用恐吓、羞耻或竞赛驱动孩子。未知的问题可以诚实回答“科学家还在研究”。

## 每页固定结构

1. 问题标题：来自孩子可能观察到的现象。
2. 第一层答案：不读第二层也能得到正确、完整的基本答案。
3. **再想一步：** 介绍一个机制、术语、比较、尺度或例外，让大人能带着孩子继续追问。
4. **图解：** 当文字涉及过程、内部结构、受力、循环或空间关系时，用一幅原理图把关键关系画出来；纯观察题不强制配图。
5. **一起看看：** 一个安全、可跳过的观察或对话。

“再想一步”不是给孩子背诵的知识点。它的任务是让答案保留科学骨架，避免把复杂现象缩成一句似是而非的口号。

## 互动

1. 每天最多一个互动，原则是“看看、听听、摸摸、比一比、说一说”。
2. 4 岁孩子不能独立接触火、热水、插座、电池、药物、道路、深水、锋利工具、强磁铁和细小可吞咽物。
3. 涉及上述对象时，只允许远距离观察，或明确写“请大人陪着”。
4. 不要求品尝野外植物、石头、海水或未知物质；不要求触碰野生动物。

## 科学口径

1. 区分“看起来”和“实际上”，例如太阳看起来跟着车走，但它并没有跟车。
2. 区分天气与气候、质量与大小、旋转与绕行、星星与行星、昆虫与所有小动物。
3. 人体内容只讲基础结构和健康习惯，不作诊断。身体不舒服时应告诉照护者或医生。
4. 地球环境内容不把复杂问题归咎于孩子；强调可理解的小行动和共同责任。
5. 资料以政府科研机构、大学、博物馆和专业科学教育机构为主，见 [SOURCES.md](SOURCES.md)。

## 插图

1. 封面和月度跨页的生成式插图不含文字、数字、标签和水印，避免乱码。
2. 封面和月度跨页采用统一的柔和纸本绘本风格；每日主题图采用清晰、可检查的矢量图形。
3. 原理图只用于真正需要视觉关系的页面，采用过程图、循环图、比较图、方向与受力图、位置关系图、协同关系图或结构图。经两轮机制审计后，每月选择 15 页，共 180 页；不以“每页都有”为目标。
4. 原理图允许 2--4 个由作者写入 SVG 的简短中文标签，但不得依赖生成模型绘制文字。箭头只表示正文明确说出的方向、作用或先后；不能确定方向时改用无箭头连线。
5. 动物肢体数量、人体部位、天体关系、光线方向、受力方向和机械连接必须检查。无法确认的生成图或矢量图不得进入正文。
6. 所有原理图明确标注“示意图·不按比例”。图帮助解释关系，不代替正文，也不暗示形状、距离、颜色或数量按真实比例绘制。
