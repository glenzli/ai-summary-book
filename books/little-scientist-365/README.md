# 小小发现家：365 天，每天一个为什么

![《小小发现家》封面：孩子和大人一起观察自然、机器、地球与星空](images/cover.png)

- **作者：** Dr. Stochastic Parrot
- **适读年龄：** 约 4 岁，建议大人陪读
- **形式：** 每天一个短问题、两层亲子解释、主题图、必要时的原理图和一个可选观察

这是一年 365 天的幼儿科普书。它从孩子每天会看见的光、雨、叶子、影子、轮子和饭菜出发，慢慢走到山川、海洋、人体、机器、行星与宇宙。每一页只回答一个问题：第一层给出通俗答案，第二层“再想一步”保留必要的科学原理，供大人根据孩子的兴趣继续讲。

## 使用说明

月份只是书签，不必按日历开始，也不必一天不漏。标题先让孩子猜，解释读到孩子愿意听的地方就好。“一起看看”以安全、轻量、可跳过为原则。180 个较依赖过程、内部结构、受力或位置关系的主题，在“再想一步”之后另有原理图；图中的短标签由大人读给孩子，不要求孩子识字。

本书的 [写作与插图约束](STYLE_GUIDE.md) 说明了年龄、安全和科学口径；[成人事实来源](SOURCES.md) 记录了用于核查的官方科学与健康教育资料。全书含 1 幅封面、12 幅月度跨页、365 幅每日主题图和 180 幅原理说明图，共 558 幅插图；检查方法与结果见 [插图验收记录](IMAGE_QA.md)。
