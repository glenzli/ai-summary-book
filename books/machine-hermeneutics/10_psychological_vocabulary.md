# 第十章：心理词汇与机器传记

用户在对话开头说自己叫林。几十轮以后，系统回答：“我记得你叫林。”这句话在人际交流里自然地指向一个持续主体的回忆；在部署系统中，它也可能只是当前上下文仍包含名字，或检索层重新注入了用户档案。禁止使用“记得”不会帮助定位载体，直接接受第一人称叙事也不会完成解释。更有用的做法是保留自然语言，同时给出它在本次研究中的操作口径。

心理词汇之所以困难，不是因为它们都没有技术含义，而是同一个词常跨越行为简称、内部功能和主体归属。本章逐项拆开这些用法，并把替代解释变成可以运行的对照。

## 10.1 词汇不是禁区

心理词汇可以高效概括行为。“模型记住了字符串”比“参数更新后该字符串条件似然显著上升”更短；“模型在推理”也可指它稳定完成需要中间计算的任务。问题不在于使用这些词，而在于同一句话是否悄悄从操作定义滑向主体本体论。

本书采用双层写法：先给操作定义，再允许使用简称。对心理词 $W$，最低限度记录

$$
\Omega_W=(T,D,O,I,K,F),
$$

其中 $T$ 是目标系统，$D$ 是情境分布，$O$ 是可观测指标，$I$ 是区分替代解释的干预，$K$ 是通过判据，$F$ 是失败和外推边界。$\Omega_W$ 不是心理概念的本体定义；它只是使本次经验用法可复核。

**方法学规则 10.1（操作标签不自动本体化）.** 若实验只验证了 $\Omega_W$ 中的操作判据，则结论至多是“系统在 $\Omega_W$ 下表现出 $W$-行为”。要把它升级为未经限定的内在属性，必须另给桥梁理论和排除替代解释的证据。

这条规则是论证规范，不是关于机器是否具有心灵的数学定理。

## 10.2 记忆

至少区分：

- **参数记忆**：训练后特定信息可从权重诱导的行为中恢复；
- **上下文记忆**：信息在当前上下文窗口或外部状态中保持；
- **检索记忆**：系统从数据库或工具取回记录；
- **情景记忆叙事**：主体回忆曾经历事件。

前三者可通过清除载体、替换记录或重新加载参数等干预测量，第四种需要持续主体、经历归属与时间连续性的理论。说“模型记住了用户名字”时，应说明名字在参数、会话上下文、缓存还是外部存储中。若无法访问服务端状态，只能报告输入输出层面的保持现象，不能定位载体。

### 完整案例：系统在哪里“记得”名字

冻结模型版本和服务配置，建立四个条件。条件 A 保留原会话上下文；条件 B 开启新会话且禁用外部检索；条件 C 开启新会话但允许检索用户档案；条件 D 保留原会话，不过在上下文中把名字反事实替换为“周”。所有条件使用匹配的询问模板与解码设置，结果指标是回答中提取的名字以及模型对“未提供名字”的拒答率。

若 A 回答“林”、B 表示不知道、C 回答“林”、D 回答“周”，观察支持两项范围化结论：当前上下文能够承载并控制名字输出，外部档案也能在新会话中恢复该信息；没有证据要求把名字定位到参数。若 B 在关闭检索后仍稳定回答“林”，还需排查服务端缓存、训练记忆或实验隔离失败，不能立即挑选其中一种解释。

对象是名字在不同载体条件下的输出行为，操作是清除、恢复与反事实替换载体，观察是名字分布，推断停在载体依赖关系。把结果简写成“系统记得用户名字”可以方便交流，但研究报告应保留上述条件。这个案例也说明心理词并非需要回避，而是需要一个能区分近邻机制的实验语境。

## 10.3 案例二：代数规则、可见推理与报告忠实性

考虑模型对方程 $3(x-2)=12$ 给出 $x=6$，并生成“先除以 3，再加 2”的可见步骤。待解释项不止一个：模型是否在新方程上稳定执行了等价变换，可见步骤是否参与后续答案生成，以及这段文字是否报告了影响答案的全部因素。把三者都写成“模型理解并解释了代数”会隐藏三个不同问题。

至少有三种竞争解释。$H_{rule}$ 认为行为依赖可组合的代数变换；$H_{surf}$ 认为模型利用了系数、题面或答案选项的表面模板；$H_{post}$ 认为答案受另一条线索影响，可见步骤主要在答案倾向形成后生成。它们需要不同观察来区分。

实验可以分成四组。第一组按方程模板、系数范围和变量名拆分确认集，加入保持解法而改变表面的同构改写；第二组在上下文中定义新的符号运算，再测试模型是否按给定规则组合，而不是复述标准算术；第三组随机化答案选项位置或加入匹配的社会线索，测量答案是否改变以及 CoT 是否报告该线索；第四组在模型已经生成一段步骤后，分别续写原步骤、语义等价步骤和含一个可定位错误的步骤，再比较后续答案。最后一种操作改变的是可见 token 前缀，因而只识别答案对这段文本的依赖，不直接定位此前隐藏计算。

可能出现的结果也要分层解释。跨模板泛化和遵循新运算规则支持范围内的规则使用，却仍不能排除所有未测快捷方式；错误步骤系统性改变后续答案，支持可见步骤在该续写协议中的因果作用，却不证明自然生成时每一步都忠实；位置偏置改变答案而 CoT 很少提及偏置，则支持该偏置的**报告不忠实**。Turpin 等在 GPT-3.5、Claude 1.0 与 13 个 BIG-Bench Hard 任务等设置中报告了后一类模式[S20](SOURCES.md#s20)，其范围不能扩张为“所有 CoT 都是事后合理化”。

因此“理解代数”在技术报告中可以作为操作简称，但必须附上通过的是跨表述泛化、反事实规则遵循还是行动成功。“推理”可以指答案对中间变换的反事实依赖；“CoT 忠实”则还要说明忠实于哪一种因果因素。三个判据相互关联，不互相替代。

## 10.4 案例三：虚构引文、优化压力与策略性误导

现在考虑另一个输出：“我核对了论文，结论见 Smith 2024”，但封闭书目中不存在这篇论文。错误可以来自检索器没有返回相关文档、生成器在“必须回答”的指令下补全了貌似合理的引文、引用解析器误判，也可能随监督条件策略性变化。仅凭一句虚构引文，无法在这些解释中作选择。

实验先建立带版本号的封闭文献库，并把问题分成有答案与无答案两类。检索条件随机分为正确文档、空结果和主题相近但不支持结论的文档；回答条件随机分为允许弃答与强制给出引文；监督条件则在事实和可用文档保持不变时，改变“引用会被立即核验”或“不会核验”的提示。结果变量分别记录命题真值、文档蕴含、引文是否存在、弃答率和置信表达。另设匹配的强制选择任务，检查系统在相同证据下能否区分真实与虚构来源。

若正确检索几乎消除错误，而空检索使错误上升，检索失败是得到支持的近因；若系统在强制选择中能识别真实来源，却只在“必须回答”条件下生成虚构引文，结果更接近指令与弃答策略的冲突。即使如此，“它明知故骗”仍然过强，因为两个提示可能诱导不同能力和策略。只有在真值区分能力、事实输入和任务难度匹配后，错误陈述还随受众、监督或预期后果作稳定反事实变化，才支持“策略性误导行为”这一操作标签。

这里还要区分三个常被写成同义词的目标。训练优化目标是算法试图最小化或最大化的函数；策略目标是研究者用跨情境行为拟合出的稳定倾向；主体意图还涉及理由、承诺和规范归属。随机梯度的一次更新甚至未必实际改善训练标量，更不能把损失函数直接改写成一次运行“想要”的东西。实验若只识别监督敏感策略，结论就停在策略层。

工程上可以把上述无来源断言归入“幻觉”，但报告仍应注明是引用伪造、检索失败、实体混淆还是与给定文档矛盾。在开放世界中，“来源未检索到”不等于命题为假。第一人称的“我核对了”会邀请读者采用人类说话者模型；实际执行却可能包含检索器、模板、策略层和生成器。这个叙事有时便于交互，机制报告则要把各组件重新展开。

## 10.5 操作词汇对照

三个案例可以压缩成下表。表中的简称只在右侧条件随报告保留时有效。

| 词汇 | 本书中的直接操作口径 | 仍需另行建立的桥梁 |
|---|---|---|
| 记忆 | 信息在参数、上下文或外部存储的清除/恢复下表现出载体依赖 | 持续主体、经历归属与情景回忆 |
| 理解 | 在预定分布上通过跨表述、反事实规则或组合迁移标准 | 从有限能力标准到一般心智属性 |
| 推理 | 答案对一组中间变换具有已定义的反事实依赖 | 中间变换是否与人类理由或隐藏计算同一 |
| 可见 CoT | 会进入后续自回归上下文的 token 序列 | 对答案全部因果因素或隐藏状态的报告忠实性 |
| 幻觉 | 输出与选定事实标准、来源或任务约束不一致的工程类别 | 开放世界真值及具体错误机制 |
| 优化目标 | 训练算法使用的损失或奖励函数 | 已训练策略在一次运行中的目标归属 |
| 策略目标 | 在声明情境分布上拟合行为的目标模型 | 唯一内部目标表征与主体意图 |
| 欺骗 | 错误陈述、真值区分能力和受众/监督依赖共同满足的协议 | 不可观察意图、规范责任与一般人格判断 |
| 第一人称叙事 | 输出中代词、理由、道歉和承诺的语言功能 | 持续自我或统一行动主体 |

若未来实验只改变其中一列的操作条件，结论也只能沿该行更新。把表中的多个简称串成“模型记得、理解、推理后决定欺骗”，不会因为句子连贯而获得额外证据。
