# 正式教材完整性标准

本文档规定《String Theory》从“主线全覆盖”进入“正式教材”的三类完整性判据。后续写作不得只增加题材，而必须提升内部闭合度和细节密度。

## 1. 内容范围完整

正式教材必须覆盖以下主线，并且每条主线至少有定义、核心命题、证明或证明状态、例子和习题：

1. Classical worldsheet：Nambu-Goto、Polyakov、约束、边界条件、conformal gauge。
2. Worldsheet CFT：OPE、Ward identity、Virasoro、free boson、ghost systems、primary fields。
3. Quantization：mode expansion、oscillator algebra、normal ordering、mass formula、physical state conditions。
4. BRST and amplitudes：gauge fixing、BRST cohomology、vertex operators、tree amplitudes、factorization。
5. Superstrings：RNS、super-Virasoro、GSO、type II、heterotic、anomaly cancellation。
6. D-branes and effective theory：T-duality、Chan-Paton factors、DBI、WZ、worldvolume gauge theory。
7. Compactification and geometry：Calabi-Yau、moduli、low-energy fields、flux stabilization。
8. Dualities and nonperturbative tests：S/U-duality、M-theory、BPS states、black branes。
9. Holography and interfaces：AdS/CFT、topological strings、mirror symmetry、QFT/geometry/number theory boundary.

## 2. 内部完整

一个章节内部完整，必须满足：

1. 章节目标与依赖明确。
2. 所有关键对象先定义再使用。
3. 每个非平凡公式声明 convention 或回指总表。
4. 每个非平凡命题标为证明、标准物理推导说明、外部输入或物理猜想。
5. 每个章节至少含一个计算例子和两个核心习题，除非该章是收束性边界章。
6. 对后文使用的结论必须在本章明确编号或在索引中登记。

## 3. 细节完整

细节完整不是把所有外部学科都重写一遍，而是保证 string theory 主线计算可以在本书内跟随：

1. 变分计算必须写出边界项和边界条件。
2. CFT 计算必须写出 OPE 奇异项和 contour/residue 逻辑。
3. 谱公式必须写出 $L_0$、normal ordering constant 和 level matching。
4. Gauge fixing 必须写出 ghost 起源、zero mode 吸收和 BRST 等价关系。
5. Duality 必须说明作用对象、受保护检验和证明状态。
6. 低能有效作用必须说明 frame、展开阶数和忽略项。

## 4. 不扩张原则

若某一外部理论只作为接口使用，则不在正文无限展开。典型例子：

- Yau theorem、Hodge theory、DUY theorem；
- modular forms 与 arithmetic geometry；
- derived algebraic geometry；
- supermoduli space 的完整构造；
- full nonperturbative definition of M-theory。

这些内容只在其服务于 string theory 主线时给出接口陈述。
