# 章节收口审定表

本文档记录每章相对于“正式教材”的状态。状态含义：

- `主线闭合`：定义、关键命题、证明或外部输入状态、练习均已能支撑后续章节。
- `教材扩写中`：主线入口和关键命题已在正文，但还需要更多例子、习题或完整计算。
- `接口章`：主题本身依赖大型外部理论，正文只给 string theory 主线所需接口。

在内容收口判定中，`教材扩写中` 不表示主线未闭合；它表示该章仍有出版化增强空间，例如增加例题、历史注、图表或把标准物理推导说明扩写成完整证明。
