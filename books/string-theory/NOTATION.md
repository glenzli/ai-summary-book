# 符号表

本文固定全书符号。若正文新增全局符号，应先更新本文档。

## 基本对象

| 符号 | 含义 |
|---|---|
| $\Sigma$ | string worldsheet |
| $M$ | target spacetime |
| $X:\Sigma\to M$ | embedding fields 或 sigma model map |
| $\sigma^a=(\tau,\sigma)$ | Lorentzian worldsheet coordinates |
| $z,\bar z$ | Euclidean complex coordinates |
| $h_{ab}$ | worldsheet metric |
| $g_{\mu\nu}$ | target-space metric |
| $\eta_{\mu\nu}$ | flat target metric, mostly plus |
| $\alpha'$ | Regge slope |
| $T$ | string tension, $T=(2\pi\alpha')^{-1}$ |
| $B_{\mu\nu}$ | Kalb-Ramond two-form |
| $\Phi$ | dilaton |
| $L_n,\bar L_n$ | Virasoro generators |
| $\alpha_n^\mu,\tilde\alpha_n^\mu$ | closed-string oscillators |
| $b,c$ | reparametrization ghosts |
| $Q_B$ | BRST charge |
| $g_s$ | string coupling |

## 状态与空间

| 符号 | 含义 |
|---|---|
| $\mathcal H$ | auxiliary/完成后的 matter state space；协变量子化中可先带不定 pairing |
| $\mathcal F_{\mathrm{fin}}$ | 固定动量的有限 oscillator excitation module |
| $\mathcal D_{\mathrm{mat}}$ | oscillator 与 Virasoro modes 的公共代数定义域 |
| $\mathcal D_{\mathrm{BRST}}$ | 有限 $L_0$-level 的 algebraic BRST complex |
| $\mathcal H_{\text{gh}}$ | ghost state module；其 pairing、zero modes 与 picture 需另行指定 |
| $\mathcal H_{\text{phys}}$ | physical state space |
| $H^\bullet(Q_B)$ | BRST cohomology |
| $N,\tilde N$ | oscillator number operators |
| $a$ | normal ordering constant |
| $c$ | central charge |
| $\mathcal M_{g,n}$ | moduli space of genus $g$ Riemann surfaces with $n$ marked points |
| $\mathscr A_n$ | 含动量 delta function 的完整连通 $S$-matrix element |
| $\mathcal M_n$ | 去掉动量 delta function 的 reduced amplitude |
| $S_{\mathrm{ren}}$ | 指定 cutoff/counterterms 后的 renormalized on-shell action |

## 状态标记

本书定理索引使用以下状态：

- `P`：正文给出证明。
- `S`：正文给出标准物理推导说明。
- `E`：外部输入定理。
- `C`：物理猜想、对偶性原则或研究边界。
