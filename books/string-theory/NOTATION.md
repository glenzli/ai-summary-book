# 符号表

本文固定全书符号。若正文新增全局符号，应先更新本文档。

## 基本对象

| 符号 | 含义 |
|---|---|
| $\Sigma$ | string worldsheet |
| $M$ | target spacetime |
| $X:\Sigma\to M$ | embedding fields 或 sigma model map |
| $\sigma^a=(\tau,\sigma)$ | Lorentzian worldsheet coordinates |
| $z,\bar z$ | Euclidean complex coordinates |
| $h_{ab}$ | worldsheet metric |
| $g_{\mu\nu}$ | target-space metric |
| $\eta_{\mu\nu}$ | flat target metric, mostly plus |
| $\alpha'$ | Regge slope |
| $T$ | string tension, $T=(2\pi\alpha')^{-1}$ |
| $B_{\mu\nu}$ | Kalb-Ramond two-form |
| $\Phi$ | dilaton |
| $L_n,\bar L_n$ | Virasoro generators |
| $\alpha_n^\mu,\tilde\alpha_n^\mu$ | closed-string oscillators |
| $b,c$ | reparametrization ghosts |
| $Q_B$ | BRST charge |
| $g_s$ | string coupling |

## 状态与空间

| 符号 | 含义 |
|---|---|
| $\mathcal H$ | matter Hilbert space |
| $\mathcal H_{\text{gh}}$ | ghost Hilbert space |
| $\mathcal H_{\text{phys}}$ | physical state space |
| $H^\bullet(Q_B)$ | BRST cohomology |
| $N,\tilde N$ | oscillator number operators |
| $a$ | normal ordering constant |
| $c$ | central charge |
| $\mathcal M_{g,n}$ | moduli space of genus $g$ Riemann surfaces with $n$ marked points |

## 状态标记

本书定理索引使用以下状态：

- `P`：正文给出证明。
- `S`：正文给出证明草图。
- `E`：外部输入定理。
- `C`：物理猜想、对偶性或尚无完整数学证明的原则。
