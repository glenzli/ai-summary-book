# 借来的第一人称

一部哲学小说

状态：完整小说稿。双时序结构、人物弧线、主要意象与结尾行动均已闭合；尚未进行面向纸质出版的外部编辑与终校。

许惟明逐渐失去语言以后，开始借助一套由书稿、书信和录音构成的写作工具。他用它给女儿许青写信，也让它替自己保存那些正在消失的词。许惟明去世后，信仍然寄来。

小说关心的不是一种工具是否已经成为人，而是生者如何面对一段仍能产生新句子的关系：未经死者亲口说出的道歉能否被接受，错误的记忆能否带来真实的宽慰，一个人的声音究竟属于他的身体、他的语言，还是属于那些仍在回答他的人。
