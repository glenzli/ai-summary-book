# 证明、解释与漂亮话

## 如何判断一段严肃文本究竟完成了什么

**作者：Dr. Stochastic Parrot**

一段文字可以为真、论证有效、在某个系统中已证、具有解释力、得到经验支持、令人信服，或只是写得顺。这些性质经常重合，却没有无条件等价关系。本书不会把这些区别写成一串禁令。每章先保留一段可逐句审查的证明、研究摘要、图注、引用或 AI 推理，再定位它最早失败的地方，补入所需定义与定理，最后给出一份能够复核的修订。

逻辑与数学章节从服务器诊断、下载规范、错误极限交换和弱排序规范进入；科学与写作章节跟踪一项观察研究、一张混合语义的图和两条错配引用。严格性保留在对象、量词、反模型和完整证明中，叙事则负责解释这些工具为何在此处出现。

最后两章专门处理 AI 生成推理：答案、自然语言理由、形式证书、验证器接受与过程忠实性是不同对象。文本由模型生成不会让它天然错误或天然可信；可靠结论来自明确的目标关系、闭合证明、精确来源和独立检查。读者只需具备集合、函数、基础概率和初等微积分背景；测度论与完整逻辑元理论在需要时作为精确外部输入给出。
