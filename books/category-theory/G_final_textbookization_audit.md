# 附录 G：终稿化审查标准

本附录规定《范畴论》从完整草稿进入可出版级终稿前必须满足的数学和编辑标准。它不是新理论章节，而是全书校订时的判定表。

## G.1 终稿状态定义

本书称为“基本终稿”，需同时满足：

1. 每章有稳定的本章目标、前置知识、定义链、命题链、本章小结和练习。
2. 每个新增术语进入 `TERM_INDEX.md`，每个新增全书符号进入 `NOTATION.md`。
3. 每个非平凡命题有证明；若不证明，则明确标为外部输入定理，并进入 `SOURCES.md` 或 `THEOREM_DEPENDENCIES.md`。
4. 每个章末练习在 `SOLUTIONS.md` 中有答案；每个综合题在 `COMPREHENSIVE_SOLUTIONS.md` 中有答案。
5. 范围不再向外部数学领域扩张；外部领域深定理只作为输入、例子或接口。
6. `validate.py` 通过，并且无禁用占位标记。

本书称为“出版级终稿”，还需满足：

1. 章节间编号、引用、术语和符号统一。
2. 核心章节的答案不只是提示，而是可独立核查的证明。
3. 每个大型外部输入定理有清楚的依赖边界：用途、来源、是否在本书内证明。
4. 每一部分至少有一组综合题，覆盖该部分的定义、主要定理和反例边界。
5. 高阶章节明确区分严格等式、同构、等价、同伦和可缩选择空间。

## G.2 逐章终稿审查表

审查每章时按以下顺序执行：

1. 读章首目标，确认本章只承诺实际证明或明确外部输入的内容。
2. 检查每个定义是否给出完整数据和公理。
3. 检查每个例子是否验证定义，而不是只列名称。
4. 检查每个反例是否指出失败的是哪条定义条件。
5. 检查每个泛性质是否写成自然同构、终对象/始对象或表示性语句。
6. 检查每个证明是否明确使用了哪个定义、自然性、泛性质或前章命题。
7. 检查练习是否覆盖定义、基本命题、计算例子和边界条件。
8. 检查答案手册是否足以让读者复原完整证明。

## G.3 第一部分终稿化重点

第一部分是全书语言基础，终稿化优先级最高。必须特别检查：

- “唯一”与“唯一到唯一同构”的区分。
- 完全、忠实、本质满、等价和同构的反例边界。
- 可表性与逐对象同构的区别。
- 极限、余极限、伴随、Kan 延拓和单子的泛性质是否都写成自然双射。
- 共尾性、反射子范畴和 Kleisli/Eilenberg-Moore 构造是否有完整证明链。

## G.4 外部输入审查表

每个外部输入定理必须记录：

1. 定理名称。
2. 使用章节。
3. 在本书中承担的逻辑角色。
4. 主要来源。
5. 不在本书内证明的原因。

若某条外部输入只是范畴论内部的标准定理，应优先考虑在后续校订中补为正文证明；若它属于外部数学领域深定理，则保持外部输入身份。

## G.5 当前终稿化状态

当前版本已达到“出版级数学内容收口”的状态。全书 0--56 章和附录 A--G 均已有稳定结构、练习与答案；外部输入边界已由 `THEOREM_DEPENDENCIES.md`、`CHAPTER_SOURCE_NOTES.md` 和 `MATH_REVIEW.md` 共同维护，并在 `THEOREM_DEPENDENCIES.md` 中补入正文编号索引。

最近一轮终稿化已处理第四十四至第五十六章的内部闭合点：语法范畴与分类 topos、正合完成与关系演算、cohesive modalities、exit-path 范畴、高阶 Morita、derivator、stacks/gerbes、范畴 Galois、polynomial functors、$\infty$-cosmoi、正交/因子化系统、sketches/doctrines 与 Karoubi/Cauchy completion。新增命题均配证明，新增练习均已同步答案。
