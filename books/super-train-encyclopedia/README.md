## “所有火车”怎么装进一本书？

世界各地两百多年的车辆有数以万计的型号，还有同一型号的改造车和小批次。假装一本书逐辆列完，反而会漏得更多。本书采用“家族地图 + 代表车型”的办法：把蒸汽、电力、柴油、动车组、高速、通勤、地铁、特急、卧铺、货运、工程、跨座单轨、悬挂单轨、胶轮、直线电机、磁悬浮、齿轨与缆索等主要设计家族都放进来，再逐个认识 120 个重要成员。

这是一张可以继续长大的地图。以后遇到新车型，先问它“从哪里取力、怎样被轨道引导、做什么工作”，就能找到它在火车大家族中的位置。
