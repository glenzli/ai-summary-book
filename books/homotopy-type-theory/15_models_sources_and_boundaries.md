# 第十五章：模型、来源与引用边界

## 本章目标

本章说明本书如何使用外部数学资料、模型论结果和近期研究。新口径下，本章不建立书稿外验收路线；它只规定：哪些结果是书内证明，哪些结果是外部输入，哪些结果只能作为研究边界。

## 依赖前置知识

本章依赖前十四章的基本 HoTT、HIT、圆的基本群和单值范畴论。读者应熟悉“书内证明”“证明说明”“外部输入”“研究边界”的状态标签。

## 15.1 来源层级

**定义 15.1（来源层级）.** 本书采用四级来源纪律。

1.  **基础教材来源**：HoTT Book、Rijke 教材和标准单值基础讲义，用于核心定义和基本定理。
2.  **论文来源**：正式论文或预印本，用于模型论、cubical type theory、合成同伦论和高阶范畴接口。
3.  **经典数学来源**：代数拓扑、范畴论、同调代数和构造性分析教材，用于外部计算和传统定理背景。
4.  **研究边界来源**：近期仍在发展的对象语言、模型、几何或高阶相干结果，只能作为边界或接口。

**规则 15.2（引用落点）.** 正文若使用外部来源，必须说明其在本书中的作用：定义来源、证明来源、模型论一致性背景、计算接口，或研究边界。只给出关键词不构成引用。

## 15.2 模型论输入

**事实 15.3（模型论的作用）.** Simplicial model、cubical type theory、presheaf model 和相关语义结果说明某些规则或公理系统的一致性、计算性或相对强度。它们是元语言定理，不是对象语言中的普通构造子。

**使用边界.** 如果正文证明只在对象语言中进行，则不得把模型论结论作为项直接使用。模型论结果只允许支撑以下说法：

1.  某组规则有已知模型；
2.  某个原则具有计算解释；
3.  某个公理与另一个公理在强度上分离；
4.  某个高级对象语言需要额外语法或语义。

## 15.3 版本化研究

**规则 15.4（近期结果）.** 涉及 2024 年以后仍在发展的结果时，正文必须记录作者、题名、版本或发布日期、使用位置和依赖风险。若结果尚未形成稳定教材定理，只能标为外部输入或研究边界。

**例 15.5.** 合成上同调、合成代数几何、directed/simplicial type theory、two-level type theory、strict Rezk completion 和 cubical HIT 元理论均属于需要版本化处理的方向。它们可以丰富教材接口，但不能回流为前十四章的隐式规则。

## 15.4 与附录 S 的关系

附录 S 现在是来源定位索引。它记录每类正文断言应回溯到哪些教材、论文或经典来源。若后续新增外部输入，应先补 `SOURCES.md`，必要时再补附录 S 的定位表。

## 15.5 封稿纪律

**原则 15.6（出版口径）.** 本书最终收口只要求文本中的定义、定理、证明状态、来源和边界一致；不以书稿外材料作为封稿条件。

**原则 15.7（高级接口不阻塞核心）.** L6-L9 的集合层数学、构造性分析、稳定同伦论、directed/cohesive/2LTT 和模型论内容可以保留为高级接口。除非它们被明确提升为核心定理，否则不阻塞 L0-L5 的 HoTT 主线封稿。

## 本章小结

本章把旧的书稿外验收路线改为文本出版口径下的来源与边界纪律。外部资料支撑本书，但不替代书内证明；模型论结果解释规则和公理，但不作为对象语言项；近期研究可以作为接口，但不改变核心 HoTT 收口。

## 练习

**练习 15.1.** 选取第十六章中的一个模型论结果，说明它为什么不是对象语言中的构造子。

**练习 15.2.** 选取第十二章中的一个高级定理，指出它在本书中是书内证明、外部输入还是研究边界。

**练习 15.3.** 阅读 `SOURCES.md` 中一个近期来源条目，判断它是否足以支持正文中的定理状态。
