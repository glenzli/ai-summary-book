# 附录 B：证明状态蓝图

## 目标

本附录给出本书在文本出版口径下使用的证明状态模板。它只服务于人工审读：读者应能看出一个断言究竟是书内证明、压缩证明、外部输入，还是研究边界。

## B.1 书内证明模板

一个标为“书内证明”的命题应包含：

1.  当前语境和所有自由变量；
2.  目标类型或命题；
3.  使用的前置定义、引理和规则；
4.  归纳或消去原则的归纳对象；
5.  关键 transport、路径复合或函数外延性步骤；
6.  结论如何回到原命题。

若证明依赖函数外延性、单值性、HIT、截断、选择或 resizing，必须在陈述或证明开头显式列出。

## B.2 证明说明模板

“证明说明”只允许用于不阻塞核心主线的长证明，且必须说明未逐行展开的内容属于哪一类：

1.  标准路径代数计算；
2.  标准范畴论记录展开；
3.  高阶相干的系统展开；
4.  外部模型论定理；
5.  经典数学计算接口。

证明说明不得掩盖未声明公理，也不得用于 L0-L5 核心链中的关键结论。

## B.3 外部输入模板

外部输入应记录：

1.  输入定理的精确陈述；
2.  来源条目；
3.  本书使用它的位置；
4.  该输入依赖的额外规则或模型；
5.  若输入被替换或删除，会影响哪些后续结果。

## B.4 研究边界模板

研究边界条目应记录：

1.  研究对象或方向；
2.  已成熟的定义或定理形态；
3.  本书只保留为接口的部分；
4.  不得回流到核心 HoTT 证明中的规则；
5.  若将来升级为正文定理，需要补哪些书内证明或外部输入。

## B.5 章节审校模板

每章收口时检查：

1.  是否有“本章目标”“依赖前置知识”“本章小结”“练习”；
2.  新符号是否进入 `NOTATION.md`；
3.  外部来源是否进入 `SOURCES.md` 或附录 S；
4.  核心定理是否有明确证明状态；
5.  高级接口是否没有伪装成核心定理；
6.  章节之间是否存在未说明的前向依赖。
