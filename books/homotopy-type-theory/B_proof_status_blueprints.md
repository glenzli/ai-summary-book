# 附录 B：证明身份与使用规则

同一个数学句子可以在对象语言中有证明，也可以只由外部模型论或经典定理支持。二者的结论即使文字相同，后续可用方式也不同。本附录固定这些身份的含义，使读者能从定理附近判断：当前项来自哪些规则，哪些步骤只是在解释外部输入，以及哪些陈述尚不进入已证明结论链。

## B.1 书内定理

一个书内定理的证明必须构造陈述类型的项。证明中应能恢复：

1. 当前语境、自由变量与宇宙层级；
2. 目标类型；
3. 使用的形成、引入、消去和计算规则；
4. 路径归纳或归纳类型消去的 motive；
5. transport、函数外延性、单值性、HIT 或截断第一次进入的位置。

若结论依赖公理化函数外延性、单值性或指定 HIT 规则，它仍可称为书内定理，但定理陈述或证明必须列出这些已经加入对象语言的原则。书内证明不能把模型中的态射相等当成语法 judgmental equality。

## B.2 外部输入定理

外部输入必须给出足以独立判断真假的精确版本：对象范围、全部假设、结论类型、来源定理号或章节，以及本书不重证的部分。后续可以使用其结论，却不能使用来源证明中没有进入陈述的数据。

例如，第十四章采用 Ahrens--Kapulkin--Shulman Theorem 8.4，结论是 weak equivalence 的限制函子对单值目标给出预范畴同构。本书可以使用这个同构及其对象函数等价；没有内部化的代表元选择和 Hom transport 计算仍属于来源证明，不能被后文当作 judgmental computation。

“证明路线（外部输入）”只解释来源证明的机制，不改变外部身份。它不能以一段启发式计算代替完整证明。

## B.3 推导、计算与条件化结果

若一段文字固定了额外输入数据，再从这些数据逐步推出结论，所得是条件化书内推导。例如第十二章先假设 EM 型塔、悬挂--loop 等价和维数输入，再计算球面上同调；存在 EM 型塔本身仍是高级输入，但降维计算由本书承担。

计算应列出每次改写的类型和合法条件。对集合截断代表元作归纳时，目标必须是集合或相应允许的低层类型；对命题截断消去时，目标必须先证明为命题。数值极限、级数和积分还要说明所用的 Cauchy 口径以及截断见证如何合法消去。

## B.4 研究边界

研究边界不是较弱的定理。它可以是尚未在本书基础语言中形成的对象、依赖特定扩展语法的元定理，或尚未给出比较翻译的两个模型。边界陈述应明确缺少哪一种数据，例如：

- 一般 QIIT 签名缺少严格正性与初始性模型；
- directed hom 需要 simplicial/directed 形成规则，不能由 identity path 定义；
- 某 cubical normalization 只覆盖指定 calculus；
- 谱序列已有各页，但尚未满足强收敛假设。

研究边界不得作为书内定理的前提，除非先升级为精确外部输入或在书内补完构造。

## B.5 四个相邻例子

1. 路径逆 $p^{-1}:y=x$ 是书内构造，因为第二章明确给出 $J$ 的 motive 和反身分支。
2. 第六章的 universe univalence 是对象语言公理；沿 $\mathsf{ua}(e)$ 的 transport 公式是使用该公理的书内定理。
3. Simplicial set 模型的存在是外部输入元定理；它给条件性相对一致性，不给对象语言闭项。
4. “任意 QIIT 都有保持 canonicity 的 cubical 模型”在本书中没有定理身份；附录 BC 只允许把具体已验证签名作为输入。

这四种身份允许同一教材同时讲内部数学、模型语义和研究方向，而不改变每个结论的逻辑强度。
