# 第零章 可解释性究竟在研究什么

“打开模型看一看”并不是一个充分的研究问题。现代模型内部有数十亿参数和海量 activation；把它们全部打印出来，只会得到更多数字。可解释性研究的任务，是在明确行为、输入分布和模型版本下，提出可检验的内部机制或表示假说。

## 0.1 四类问题

可解释性研究常在回答四类不同问题：

1. **行为描述**：什么输入会触发什么输出？
2. **信息定位**：关于某属性的信息能从哪里读出？
3. **因果归因**：哪些内部变量的变化会改变目标输出？
4. **机制解释**：哪些组件怎样组合成可重复的计算过程？

“某层可以线性预测法语”属于第二类；“删除某方向使法语输出下降”接近第三类；只有说明信息如何进入、传递并作用于 logits，才开始进入第四类。

## 0.2 解释对象

解释必须先指定目标 $T$。它可以是：

- 某个 token 的 logit difference；
- 某类回答的概率；
- 拒答、幻觉或工具调用行为；
- 某个 benchmark 上的算法；
- 跨输入保持的特征或回路；
- 训练过程中形成的表示变化。

同一模型对不同目标可能使用不同机制。同一个目标在不同提示、语言或模型尺度上也可能由不同路径实现。

## 0.3 局部与全局

**局部解释**针对一个或一小类输入，例如“为什么这条提示使模型输出 Paris”。它可以详细追踪特定 activation 路径，但不自动推广到所有事实回忆。

**全局解释**试图描述一个分布上的稳定结构，例如“某组 attention heads 通常执行间接对象识别”。它需要跨大量正例、反例、扰动和模型运行验证，难度显著更高。

局部图很漂亮不等于全局机制成立；全局平均统计也可能遗漏个别输入上的替代路径。

## 0.4 解释的四种强度

本卷把主张按证据强度区分为：

| 强度 | 典型证据 | 可以支持 |
|---|---|---|
| 描述性 | activation 最大样本、可视化、相关性 | 该单位与某输入模式共同出现 |
| 预测性 | held-out probe、自动解释预测新样本 | 表示包含可泛化读出信息 |
| 干预性 | ablation、patching、steering、因果对照 | 修改单位会改变指定行为 |
| 机制性 | 可组合回路、必要/充分性测试、跨分布验证 | 一组组件按所述方式实现部分计算 |

后一层通常需要前层证据，但相关观察不能直接升级为机制解释。

## 0.5 内部对象不是天然概念

神经元、attention head、residual direction、SAE feature 和 attribution graph node 都是分析单位。它们由架构或分析方法定义，不天然对应“否定”“法国”或“欺骗”等人类概念。

给内部单位命名是一条假说：名称应预测它在新输入上的激活和干预效果。一个贴切故事若不能预测反例，只是方便记忆的标签。

## 0.6 两种忠实性

解释至少涉及：

- **模型忠实性**：解释是否描述原模型实际使用的计算；
- **人类可理解性**：解释是否能被人读懂并用于预测。

两者可能冲突。简单线性说明容易理解，却可能遗漏关键非线性；逐元素列出完整计算轨迹保留了更多计算细节，却几乎没有认知压缩。研究方法要明确它舍弃了什么，并用行为保真度或干预测试量化损失。

## 0.7 可解释性不等于透明产品说明

数据卡、系统卡、评测报告和日志解释模型怎样被训练与部署；机制可解释性研究模型内部怎样计算。两者互补但不同。

同样，可解释性不是安全证明。发现一个与危险行为相关的 feature 可以帮助诊断，不能保证所有危险路径都被发现，也不能证明部署系统在未来输入上安全。

## 0.8 当前主要路线

本卷按研究方法而不是按抽象“解释层级”组织：

1. 行为与反事实测试；
2. 梯度和输入归因；
3. attention 与残差读出；
4. probes 与表示几何；
5. 神经元、feature 与自动解释；
6. ablation、patching 与因果追踪；
7. circuits 与路径分析；
8. superposition、SAE 与 steering；
9. 训练动力学、推理过程与监测；
10. 跨方法评估和案例研究。

这些路线相互竞争也相互补充。可解释性仍是一个方法和评估标准都在快速变化的领域，不存在一套公认完备的“模型显微镜”。

## 0.9 一个最小研究模板

任何解释实验都应先写：

- 模型、checkpoint、tokenizer 和代码版本；
- 目标行为与输出指标；
- 正例、负例和对照输入怎样构造；
- 观察或干预的是哪个内部对象；
- 假说在 held-out 数据上预测什么；
- 哪个结果会推翻假说；
- 解释覆盖哪些输入，不覆盖哪些输入。

这组信息比“发现一个负责 X 的神经元”更接近可检验科学主张。
