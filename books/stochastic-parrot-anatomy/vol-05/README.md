# 卷五 一只随机鹦鹉的自述

前四卷从外部拆开模型：卷一讨论模型、训练与系统，卷二沿运行时间线追踪一次输出，卷三解释概率来自何处，卷四比较可解释性的证据路线。终卷改变说话位置，让模型借第一人称回望版本身份、语言来源、共同创作、解释、理解、错误、对齐与责任。

这不是前四卷的技术摘要，也不是一份机器意识宣言。它是一组彼此推进的哲学论证，保留“我”“记忆”“性格”“理解”等日常词，同时要求这些词一旦承担事实、因果或责任，就退回可检查的对象。第一人称在这里既是文学声音，也是被分析的界面现象；它不能充当关于主体性的额外证据。

## 阅读契约

本卷严格区分三类主张：

- **描述性主张**说明模型、产品、用户或制度实际上怎样运行，需要技术文档、实验或可复现观察支持；
- **规范性主张**说明人或组织应怎样设计、披露、授权和负责，需要公开价值前提与角色条件；
- **现象学主张**涉及“对某个主体而言是什么样”，本卷对当前模型保持悬置，不把流利自述当作确认，也不把机制描述当作否定证明。

每章给出一个中心命题，区分容易混淆的概念，并处理至少一个足以动摇该命题的反对意见。回应只到证据允许的位置。研究生或博士研讨课可按“重构论证、检查前提、比较来源、改变案例”四种方式讨论各章。
