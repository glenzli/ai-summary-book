# 术语表

| 术语 | 本书口径 |
| --- | --- |
| 模型工件 | 可加载的参数化计算对象及其架构、权重、tokenizer、精度、adapter、量化和推理约定 |
| 基座模型 | 以预训练目标获得、尚未等同于完整助手或部署系统的模型工件 |
| 后训练 | 在预训练后通过 SFT、偏好优化、强化学习、蒸馏等改变交互行为的训练阶段 |
| 模型生命周期 | 从数据采集、训练快照和工件派生到部署、更新、遗忘与退役的对象关系；不是单一版本号 |
| 机器遗忘 | 使模型相对于声明遗忘集接近“未训练该数据”的算法与验证问题；有限行为测试不等于精确分布等价 |
| VC 维 | 假设类能够打散的最大有限点集规模；它描述组合容量，不直接等于某个训练算法的测试误差 |
| 偏差--方差分解 | 平方损失和指定训练随机机制下，把条件测试误差拆成噪声、平方偏差和预测器方差的恒等式 |
| 近端映射 | 由局部正则化子问题定义的更新算子；$L^1$ 与欧氏二次项的近端映射是 soft-threshold |
| 系统 | 模型、上下文、检索、工具、权限、运行时、日志、缓存、外部服务和组织流程的组合 |
| 边界条件 | 使一次执行成为单值实现或随机核所需固定的工件、上下文、随机流、外部事件和环境 |
| 运行 | 系统从初始状态经历事件、工具调用和提交到终止或挂起的具体过程 |
| 输出 | 相对于系统边界和观察关系得到的对象族，不默认等于屏幕文本 |
| token | 模型处理的离散单位；不是天然语义单位，也不等于 Unicode 字符 |
| tokenizer 规范像 | 实际由编码器产生的 token 序列集合；round-trip 只保证解码器在该像上是编码器的逆 |
| artifact | 可保存、复制、签名、引用或审计的数据制品 |
| provenance | 记录 entity、activity、agent 及其关系的来源图 |
| commit | 输出片段或副作用越过协议规定的提交边界；提交后不保证可直接撤回 |
| 幂等键 | 将多次传输重试绑定到同一逻辑操作的标识；它降低重复副作用风险，不证明首次调用成功 |
| RAG | 将检索结果组装进生成上下文的系统模式；事实证据仍来自被核验来源 |
| Agent | 带状态、观察、行动、工具和停止条件的工程闭环；该术语不蕴含人格或心理主体性 |
| 模型策略 | 从上下文或状态到候选输出/行动分布的模型接口，不等于系统权限策略 |
| 世界模型 | 对环境潜在状态转移和观测生成的预测模型；“世界”相对于数据、传感器和行动接口 |
| VLA | Vision-Language-Action 模型，把视觉、语言条件与机器人动作接口连接起来；模型动作仍须经过规划、控制和独立安全门 |
| 概率对象 | 明确样本空间、事件族、测度、随机变量和条件信息后的数学对象 |
| Markov 核 | 对每个输入给出一个输出概率测度的可测接口；有限情形可视为行随机矩阵 |
| 条件期望 | 在给定信息 $\sigma$-代数下保持所有可测事件积分的随机变量，通常只在几乎处处意义下唯一 |
| 绝对连续 | 一个测度不在另一测度的零测集上分配正质量；记作 $P\ll Q$ |
| token 概率 | 在模型与前缀条件下对下一个 token 或序列的分布；不是命题真值概率 |
| 观察者不确定性 | 观察者缺少完整状态时的认知状态，不等于系统内部随机性 |
| 校准 | 在声明预测事件和评测分布上，预测概率与经验频率的对应性质 |
| 适当评分规则 | 使如实报告预测分布在期望上最优的评分规则；仍不提供事实来源 |
| 严格适当评分规则 | 如实报告真实分布是期望评分的唯一最优解；唯一性仍相对于声明的事件、报告类和数据分布 |
| Bayes 行动 | 在给定后验、行动集合和损失函数下最小化后验风险的行动；不自动给出伦理或法律许可 |
| 复现合同 | 规定输入域、规范化、前置条件、比较关系和判定算法的可执行协议 |
| TOST | 以两个单侧检验拒绝“差异超出等价界”的等效性检验；不显著的零差异检验不能替代它 |
| FWER | 一族检验中至少错误拒绝一个真零假设的概率；Holm step-down 可在有效边际 p 值下控制它 |
| `Inconclusive` | 前置条件或必要证据缺失，因而合同不能判定通过或失败；不等于 `Fail` |
| 评测协议 | 任务总体、抽样、上下文、工具、评分器、聚合和不确定性报告的组合 |
| 能力主张 | 绑定任务总体、系统条件、资源、评分器、阈值和保证的范围化陈述 |
| 数据污染 | 评测题、答案或近重复内容进入训练或调参过程，破坏预期的未见样本解释 |
| 学习型裁判 | 用模型按 rubric 评价候选输出的评分系统；其标签依赖裁判工件、呈现顺序、提示、解码和解析器，不是自动真值 |
| 被解释项 | 解释试图回答的具体对象，例如行为事件、logit 差、工具选择或内部状态变化 |
| 归因 | 在指定基线、局部函数和指标下把输出变化分配给输入或组件的分析 |
| 探针 | 从内部表示预测某属性的辅助模型；可解码性不自动等于下游因果使用 |
| activation patching | 在配对运行间替换内部激活并测量目标变化的干预方法 |
| 观察等价 | 两个内部对象在声明事件与观察函数下产生相同可观察行为；不要求内部状态相等 |
| 强确定 LTS | 每个状态至多有一个下一状态的转移系统；正常终止还需另列进展和终止无后继条件 |
| 线性扩张 | 保持有限偏序中全部先后约束的全序；合法并发调度常被表示为线性扩张 |
| 电路主张 | 声称一组内部组件及连接在声明输入域内实现某种计算的范围化主张 |
| SAE | 稀疏自编码器；用于把激活近似分解为稀疏特征，特征语义和唯一性仍需检验 |
| proof obligation | 使主张达到合法终态所需关闭的定义、证明、计算、经验或来源义务 |
| 计算证书 | 可由验证器检查的形式对象；验证器接受不自动证明自然语言目标翻译正确 |
| 弱规格 | 只覆盖目标性质真子集的规格；验证通过只支持被形式化的部分 |
| unit roundoff | 在指定浮点格式与舍入模型中控制单次相对舍入误差的参数；不是跨硬件的默认常数 |
| process faithfulness | 可见理由与实际产生过程之间在指定抽象下的对应 |
| 选择偏差 | 在同一有噪声数据上从多个候选中挑最大值再报告所引入的乐观偏差；独立确认或选择后推断需另行处理 |
| 显式定义 | 用旧语言公式唯一规定新符号解释的保守扩张接口；它不能单独制造旧语言中的新事实 |
| prompt injection | 不可信数据诱导模型或运行时偏离授权指令/策略的攻击或失败模式 |
| 安全能力 | 由运行时签发并限制主体、资源、动作、范围、期限和委托的权限凭证；模型生成文本不能自行创造能力 |
| confused deputy | 有权限的中介误把低权限来源的数据当成授权，继而用自己的能力替该来源执行动作 |
| 污点标签 | 随数据派生传播的来源、敏感性和用途标记；改变标签需要声明的验证或降密步骤 |
| 物理提交 | 动作越过纯信息层并开始改变机械或现实状态的边界；取消与补偿必须考虑动量、接触和不可逆后果 |
| dry-run | 不提交现实副作用的模拟执行；必须声明它与真实执行共享和不共享的路径 |
| 回滚 | 恢复先前状态；不可逆操作只能采用补偿措施，不能伪称已撤销 |
| 因果参与 | 某组件位于结果产生路径；不自动等于法律、道德或组织责任 |
| 调用责任 | 由角色、权限、审批、副作用、可预见性、日志、补偿和制度规则共同决定的责任结构 |
| 审计包 | 把输出记录、来源、复现合同、主张表、解释报告、工具事件和责任链合成的证据集合 |
