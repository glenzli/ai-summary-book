# 第十二章 训练与推理复现

训练复现比较的是长状态轨迹：初始化、样本顺序、增强、梯度、优化器更新与 checkpoint 共同决定终点。推理复现通常轨迹较短，却仍受批处理、缓存、量化、解码和服务并发影响；二者不能共享一份只写“模型和 seed”的简化合同。

这一章分别给出训练与推理的最小充分记录，并区分逐位重放、数值近似、行为一致和统计复制。目标不是许诺所有平台产生相同字节，而是让每一种相同性主张都有可检查的输入边界、比较器和失败证据。

## 训练复现的条件与证据

一个只有实参数 $w$ 的模型也足以说明训练轨迹为何需要完整输入。取单样本损失
$L_y(w)=\tfrac12(w-y)^2$、学习率 $1/2$、初值 $w_0=0$，数据目标为 $1$ 与 $3$。
按次序 $(1,3)$ 训练时，

$$
w_1=0-\frac12(0-1)=\frac12,
\qquad
w_2=\frac12-\frac12\left(\frac12-3\right)=\frac74.
$$

按次序 $(3,1)$ 训练则得到 $w_1=3/2$、$w_2=5/4$。两次运行使用同一数据多重集、
同一模型、同一目标函数和同一学习率，最终参数仍不同。数据顺序不是附属日志，而是
训练映射的输入；在真实系统中，它还与 RNG 子流、worker 调度、浮点内核、选择规则
和恢复状态共同决定轨迹。

### R5.1 把训练运行写成有类型的部分函数

固定训练实现 $I$。一次训练输入写成

$$
x=(D,A,Z_0,O_0,R,N,S,Q,E),
$$

其中：

- $D$：数据内容、模式、split、顺序与预处理；
- $A$：模型结构、目标函数和训练算法配置；
- $Z_0$：模型参数、缓冲区与其他初态；
- $O_0$：优化器、scheduler、梯度缩放器等状态；
- $R$：全部 RNG 当前状态及逻辑任务到子流的映射；
- $N$：浮点格式、核、编译与约简语义；
- $S$：调度、设备流、rank 映射和故障恢复事件；
- $Q$：早停、checkpoint、超参数与报告选择规则；
- $E$：其余软件、硬件和外部服务环境。

训练实现是部分函数

$$
\operatorname{Train}_I:\mathcal X_I\rightharpoonup
(\Theta,\mathcal L,\mathcal A,\mathcal Z),
$$

输出依次为最终/候选参数、轨迹日志、制品与终止状态。OOM、未定义算子、数据错误和永不终止都可能使通常的“成功输出”不存在，因此定义域必须进入合同。

**命题 R5.1（闭合确定实现中的条件充分性）.** 若 $\operatorname{Train}_I$ 在 $x$ 处有定义且是单值函数，则任何两次具有相同 $I$ 与相同输入元组 $x$ 的抽象执行产生相同输出四元组。

**证明.** 函数在同一自变量处只有一个函数值。两次抽象执行均等于 $\operatorname{Train}_I(x)$，故输出相同。证毕。

命题是一个模型内充分条件，不是现实中的记录清单定理。若服务响应、调度或核选择实际上影响输出却未进入 $x$，现实过程就没有被该函数闭合建模。

### R5.2 必要条件与充分条件不能互换

相对于“checkpoint 逐位身份”这一目标：

- 固定所有实际影响字节的输入，在闭合确定模型中是充分条件；
- 某字段的删项区分见证只说明删去它后的当前记录不充分；若称该信息在一类记录中“必要”，还要证明不存在编码同一信息的替代表示；
- 相同 GPU 型号不充分：隐藏数据仍可不同；而两个不同设备也可能在某有限合同域上产生相同字节，所以“设备型号相同”不是无条件必要条件；
- 相同 seed 通常不充分；若训练完全不读取 RNG，则删除 seed 字段不会改变观察；
- 相同源码不固定编译器、依赖、数据和运行时，所以不充分；不同源码也可能在合同域上实现同一观察函数。

工程清单的作用是缩小未记录变量，不是自动完成逻辑上的最小性或充分性证明。

### R5.3 随机性与执行非确定性

参数初始化、shuffle、augmentation、dropout、采样器和强化学习 rollout 是模型显式使用的随机变量。线程到达顺序、非确定内核、autotuning 和外部服务漂移是执行层多轨迹来源。混合精度 overflow 分支本身通常是前序数值状态的确定后果；只有当前序状态因随机或调度而异时，它才表现为运行间差异。

记录随机性至少包括生成器算法/版本、当前状态、派生规则、worker/rank 标识和消费顺序。把一个整数 seed 写进配置，不等价于记录 $R$。

### R5.4 checkpoint 的续接条件

一个训练 checkpoint 若要续接逐步轨迹，应编码第二区分的观察充分状态。候选项包括：

- 参数、非参数缓冲、梯度累积与优化器状态；
- scheduler、梯度缩放器、全局 step 与阶段状态；
- 全部 RNG 当前状态与子流映射；
- 数据迭代器游标、排列、shuffle 缓冲和 worker 队列；
- rank/world-size 映射、通信桶和一致快照边界；
- 早停统计、最佳 checkpoint 候选集合和平局规则。

恢复到“同一 epoch 编号”不是状态身份；一个 epoch 内的游标和随机消费仍可能不同。第十一章的一致割要求也适用于分布式 checkpoint。

### R5.5 先决定要复现训练的哪一层

1. **轨迹复现**：step 级批次、状态和日志在指定投影下相同；
2. **配置复现**：给定已选配置，重新训练得到合同允许的结果；
3. **方法复现**：重做搜索、失败处理、选择和报告流程；
4. **统计复现**：独立训练运行形成样本，目标量与参考结果相容。

轨迹复现通常要求最完整的状态控制，但并不自动比方法复现提供更独立的科学证据。配置复现也不能验证原研究的搜索过程是否偏向幸运配置。

### R5.6 测试样本与训练运行不是同一实验单位

设方法 $a$ 的第 $j$ 次独立训练产生模型 $\Theta_{a,j}$，在测试样本 $k$ 上得到损失 $L_{a,j,k}$。一个简单层级分解是

$$
L_{a,j,k}=\mu_a+U_{a,j}+\varepsilon_{a,j,k},
$$

其中各项假设可积，并施加中心化条件

$$
\mathbb E[U_{a,j}]=0,
\qquad
\mathbb E[\varepsilon_{a,j,k}\mid U_{a,j}]=0.
$$

于是 $\mu_a=\mathbb E[L_{a,j,k}]$；$U_{a,j}$ 表示训练运行间差异，$\varepsilon_{a,j,k}$ 表示固定运行效应条件下的测试样本差异。该式只是建模模板而非普遍真理：跨 $j$ 的独立性、同一测试对象在不同模型间诱导的相关性、异方差和数据重用都需要由设计声明或另建模型，不能从分解式本身推出。

只对固定模型的测试样本 bootstrap 主要反映 $\varepsilon$ 层，不能凭空估计只有一次训练时的 $U$ 层方差。要推断“训练过程的期望性能”，独立训练运行才是相应实验单位。

### R5.7 配对运行

若方法 A、B 在第 $j$ 个实验块中共享同一数据 split、资源预算和预先定义的随机因素映射，可分析

$$
D_j=M_{A,j}-M_{B,j}.
$$

配对的价值来自块内协变量控制及 $M_{A,j},M_{B,j}$ 的相关性，而不是 seed 整数相同本身。架构不同会改变随机数调用图；因此应把配对写成从块 ID 到两套初态/随机流的设计函数，并说明哪些随机因素共享、哪些独立。

用于均值区间的 Student-$t$、bootstrap 或随机化推断各有假设；本章不把小样本正态近似写成无条件定理。具体判决在第十四章中声明。

### R5.8 “最好 checkpoint”带来的选择效应

**命题 R5.2（从候选中取最大值产生非负选择增益）.** 设 $T\ge1$ 为整数。若可积随机变量 $V_1,\ldots,V_T$ 表示 $T$ 个候选的验证分数，则

$$
\mathbb E\!\left[\max_{1\le t\le T}V_t\right]
\ge
\max_{1\le t\le T}\mathbb E[V_t].
$$

**证明.** 因 $T<\infty$ 且

$$
\left|\max_{1\le t\le T}V_t\right|
\le\max_{1\le t\le T}|V_t|
\le\sum_{t=1}^{T}|V_t|,
$$

随机变量 $\max_tV_t$ 可积。对每个固定 $j$，逐点有 $\max_tV_t\ge V_j$。取期望得 $\mathbb E[\max_tV_t]\ge\mathbb E[V_j]$；再对有限个 $j$ 取最大即得结论。证毕。

该命题不量化偏差大小，也不要求候选独立；但它说明把最高验证分数当作未选择估计会系统性忽略选择。最终性能应在未参与选择的数据上评估，或用嵌套设计、选择后推断等明确方法。

方法复现应记录搜索空间、预算、优化器/调度器、并行试验、提前终止、失败试验处理、候选集合和最终选择规则。只发布 `best.pt` 与最终超参数，只支持较弱的配置复现。

### R5.9 数据泄漏与谱系

实体重叠、时间穿越、在完整数据上拟合预处理、基准污染和重复样本都可能泄漏。固定 seed 可以稳定地重复泄漏。因而训练合同必须验证数据内容、split 生成程序、去重键、时间边界和预处理拟合范围，而不只保存索引文件。

受限数据无法公开时，应提供内容承诺、模式、生成/变换代码、访问程序和可信复核方式，并把外部团队无法独立检查的部分列为证据边界。

### R5.10 把条件与主张逐项对齐

| 目标 | 典型充分条件（仅在固定实现模型内） | 单独不足的常见条件 |
|---|---|---|
| step 轨迹身份 | 输入元组 $x$ 全同且实现单值、运行成功 | 同 seed、同源码、同 GPU |
| checkpoint 字节身份 | 轨迹身份加固定序列化/元数据 | 权重数值相同 |
| 指标容差 | 明确数据、评测函数和误差界 | “大约一样” |
| 多运行统计相容 | 明确实验单位、设计、样本量和判决 | 单次最佳 seed |
| 方法复现 | 搜索、失败、选择、报告流程均进入合同 | 只发布最终配置 |

这些行不宣称条件最小，也不宣称跨实现必要。

两样本计算说明，数据内容相同并不能替代数据次序相同；命题 R5.1 则说明，一旦实现
和完整输入真正闭合，重复执行不再需要额外的“运气”。实际报告还必须选择轨迹、
配置、方法或统计目标，并把独立训练运行与测试样本分层。训练结束后，同一模型制品
进入推理服务，动态合批、量化和近并列 logits 又会引入新的观察边界。

### R5 练习

**练习 R5.2.** 用第 5.6 节层级模型解释测试样本 bootstrap 为何不能估计训练运行方差，并说明在哪种目标量下它仍有用。

**练习 R5.3.** 设计两个方法的配对多运行比较，明确块、共享随机因素、独立随机因素和实验单位。

**练习 R5.4.** 给出 checkpoint 最大化偏差的数值例子，并区分命题 R5.2 与“偏差必严格为正”。

**练习 R5.5.** 分别列出配置复现、轨迹复现、统计复现和方法复现所需制品，并指出至少两个非必要但便利的条件。

## 推理、采样与服务端漂移

某一步解码只有两个候选 token，logits 为 $(1,0.9999998)$，最大间隔是
$2\times10^{-7}$。单请求执行保持这个顺序；动态批执行产生扰动
$(-1.1\times10^{-7},1.1\times10^{-7})$，新 logits 变成
$(0.99999989,0.99999991)$，greedy token 随之翻转。两个程序都没有采样；差异来自
数值路径，而首 token 的变化又改变了下一步 logit 函数的输入。

这个例子说明，“温度为零”不是完整的复现条件。权重、tokenizer、并列规则、批处理、
KV cache、数值内核和停止条件共同组成一次推理调用；若调用工具，外部世界还会继续
扩展输入。下面先给这份输入定型，再判断 greedy、随机采样和黑箱服务分别能要求何种
复现。

### R6.1 一次推理调用还包含什么

固定推理实现 $I$，一次调用写成

$$
x=(\Theta,T,X,D,R,N,B,E,W),
$$

其中 $\Theta$ 是权重、适配器和量化制品，$T$ 是 tokenizer/规范化/chat 模板，$X$ 是规范输入，$D$ 是解码与停止规则，$R$ 是 RNG 当前状态，$N$ 是数值核与编译语义，$B$ 是批处理和 KV cache 调度，$E$ 是运行环境，$W$ 是工具及外部世界状态。

推理是部分函数

$$
\operatorname{Infer}_I:\mathcal X_I\rightharpoonup
(\text{token trace},\text{bytes},\text{tool trace},\text{status}).
$$

在闭合确定模型内，相同 $I$ 与完整 $x$ 相同足以得到相同输出；但公开 API 往往不暴露 $\Theta,N,B,E$ 或系统提示的精确版本，所以调用方无法验证这些充分条件。

### R6.2 greedy 解码的唯一性

设词表 $V$ 是带固定全序 $\triangleleft$ 的有限集合。给定前缀 $p$，实现产生 logit 向量 $\ell(p)\in\mathbb R^V$；greedy 规则选择最大 logit，若并列则选 $\triangleleft$ 最小者。

**定理 R6.1（固定确定模型下 greedy 轨迹唯一）.** 假设 tokenizer、前缀更新、logit 函数 $\ell$、并列规则、停止谓词和最大步数 $L<\infty$ 都是全定义确定函数。则对任意合法输入，greedy 解码产生唯一的有限 token 轨迹。

**证明.** 对步数归纳。初始前缀由输入唯一确定。若第 $k$ 步前缀唯一，则有限集合 $V$ 上的 logit 向量唯一；最大值集合非空，固定全序从中选出唯一 token。前缀更新和停止谓词确定，故下一前缀或终止状态唯一。最大步数 $L$ 保证过程有限结束。证毕。

“温度为零”只有在服务把它精确定义为这套规则时才可代替上述条件。若服务仍保留隐藏随机路由或不公开并列规则，调用方不能由参数名推出定理假设成立。

### R6.3 近并列 token 怎样发生翻转

**命题 R6.2（唯一最大值的扰动稳定性）.** 设 $i^*$ 是 $\ell\in\mathbb R^V$ 的唯一最大分量，并定义间隔

$$
m=\ell_{i^*}-\max_{j\ne i^*}\ell_j>0.
$$

若扰动 $e$ 满足 $\|e\|_\infty<m/2$，则 $i^*$ 仍是 $\ell+e$ 的唯一最大分量。

**证明.** 对任意 $j\ne i^*$，

$$
(\ell_{i^*}+e_{i^*})-(\ell_j+e_j)
\ge m-|e_{i^*}|-|e_j|
>m-2(m/2)=0.
$$

故所有竞争分量仍严格小于第 $i^*$ 分量。证毕。

在章首计算中，$m=2\times10^{-7}$，而
$\lVert e\rVert_\infty=1.1\times10^{-7}>m/2$，所以命题的稳定条件不成立；直接计算
又确认最大分量确实交换。若改用扰动
$(-0.9\times10^{-7},0.9\times10^{-7})$，新间隔仍为 $0.2\times10^{-7}>0$，
token 不变。前者说明分叉如何发生，后者说明小于半间隔的界为何足够。

当 $m\le2\|e\|_\infty$ 时，命题不保证 argmax 改变，只是稳定性证明失效。首 token 一旦改变，自回归前缀改变，后续 logit 函数的自变量也改变，因此末位扰动可以导致长程离散分叉。

### R6.4 随机采样的两种复现

对每个前缀，解码规则把 logits 转成词表概率向量 $p\in\Delta(V)$，再由随机字 $U_k$ 选择 token。若固定：

- 概率计算的数值结果；
- 词表排序、并列和 top-$k$/top-$p$ 边界；
- PRNG 算法、当前状态和随机字消费顺序；
- 批处理、停止和最大长度；

则采样轨迹在第十章模型中可逐步复现。只固定 seed 而改变批大小或提前终止其他序列，可能改变后续随机字分配。

另一目标是**分布复现**：独立重复应服从相同条件分布，而不要求第 $j$ 个样本逐 token 对齐。有限样本只能按第十四章的统计合同评估相容性。

top-$p$ 还必须说明排序稳定性、累计概率等于阈值时是否纳入边界 token、最小保留数和重归一化精度。否则“同一 top-$p$”不是完整算法。

### R6.5 动态合批与 KV cache

在线服务可按到达时间动态合批，改变矩阵形状、核选择、约简路径、KV cache 页面布局和请求调度。数学上的逐序列注意力函数可能相同，具体浮点程序却可能给出不同 logits。

测试矩阵至少应交叉：单请求/固定批/动态批、短/长上下文、普通/近并列 margin、不同并发负载和 cache 命中状态。若目标是安全政策或离散工具动作，应特别检查小数值差异是否跨越决策边界。

### R6.6 量化、适配器与编译

“同一模型名”不能标识数值函数。模型制品至少包括：权重内容、架构、tokenizer、适配器集合与加载/合并顺序、逐层量化格式和尺度、校准数据标识、KV cache 精度、运行时与图编译标志。

不同量化、FMA 收缩、算子融合和 kernel autotuning 可改变 $N$。在某个逐位记录方案中，删除这些字段可能有区分见证；对只比较任务标签的合同则可能没有。是否忽略它们，应由 margin 证明、误差界或明确有限域的经验覆盖支持。

### R6.7 工具与外部世界

Agent 输出还依赖搜索、数据库、代码执行、文件系统和时间。工具调用可分为两种实验：

- **replay**：固定初始沙箱并重放已保存响应，验证给定观察下的控制逻辑；
- **live**：访问真实服务，测量包含服务漂移、网络和权限在内的部署行为。

replay 成功不证明 live 长期稳定；live 失败也不能在未比较工具响应前归因于模型。工具合同应保存规范请求、响应内容或受限内容承诺、服务版本、时间窗口、错误/重试和调用顺序。

### R6.8 黑箱服务

模型别名、系统提示、安全策略、路由和后端权重可能不透明更新。供应商给出的版本 ID 或 fingerprint 是状态描述的一部分，不是“后端完全相同”的数学证明；其语义以供应商文档为准。

有限哨兵集可以形成可判定行为合同：对固定输入集合重复调用，比较 token、logprob、任务指标与安全不变量。哨兵全部通过只支持该有限集合和采样设计上的结论，不能推出输入全域上的函数身份。

当隐藏状态无法固定时，诚实的结论是“逐位合同不可验证”或 `INCONCLUSIVE`，而不是把观察到的一次相同输出升级为服务恒等。

### R6.9 一次服务验收应保留哪些层次

一次推理报告可同时给出：

1. 规范响应字节身份；
2. token 轨迹与逐 token logprob 差异；
3. 任务标签、结构化 schema 和不变量；
4. 多次采样的分布统计；
5. replay 与 live 工具结果；
6. 服务版本和不可控变量。

这些指标回答不同问题，不应压成无解释的单一 pass/fail。

章首 token 的翻转发生在确定性 argmax 之前，不能归因于“模型采样”；稳定性取决于
logit 间隔与数值扰动的相对大小。随机解码还要固定随机字消费，工具调用则要区分
replay 与 live。要让另一团队知道它究竟加载了哪份权重、模板、量化与数据，下一步
必须从运行行为退回制品内容和谱系。

### R6 练习

**练习 R6.1.** 构造两个 top logits 间隔为 $m$ 的例子，分别给出小于 $m/2$ 与超过 $m/2$ 的无穷范数扰动；说明命题 R6.2 的充分性而非必要性。

**练习 R6.2.** 为 top-$p$ 采样写出同 seed 同序列的充分条件，并给出同 seed 仍失败的批处理反例。

**练习 R6.3.** 设计动态合批的复现测试矩阵，指定每个单元比较的观察层。

**练习 R6.4.** 比较工具响应 replay 与实时调用所验证的主张，并给出二者可能得出相反判决的例子。

**练习 R6.5.** 为黑箱模型 API 设计有限行为哨兵；准确写出“全部通过”后允许宣称什么、不允许宣称什么。

## 训练与推理合同接口

### S9.6 训练复现

训练复现可分成：

1. 逐位同 checkpoint；
2. 指标容差内同模型；
3. 统计相容的性能；
4. 独立重复支持同一结论。

“我重新训练得到差不多的模型”需要说明是哪一层。最好 checkpoint 的选择还带来选择效应：如果多次训练后挑最优，复现实验也必须复现选择协议，而不是只复现一次训练。

### S9.7 推理复现

一次推理调用包含模型、上下文、解码、随机流、工具返回、服务端路由、缓存、安全层和输出序列化。服务端黑箱时，用户常缺少隐藏上下文、系统提示、模型精确版本和路由信息，因此只能定义外部验收合同。

合格验收例子：

> 在固定公开输入、固定工具模拟响应和固定规范化函数下，最终文本主张集合相同即 Pass；若工具无法访问或服务端版本未知，则 Inconclusive。
