# 第十七章：正式分析工作流与发布标准

## 本章目标

本章把本书的技术纪律整理成正式分析报告标准。它适用于论文阅读、内部计算记录和实验结果的 EFT 解释。

## 依赖前置知识

需要第八章的工作流、第十二章的有效性边界和第十四章的 Wilson 空间纪律。

## 17.1 最小报告单元

**规则 17.1（SMEFT 结果最小元数据）.** 一个 SMEFT 约束或预测至少报告：

1.  EFT 类型：SMEFT、HEFT、LEFT 或其他；
2.  算符基；
3.  Wilson 系数定义尺度；
4.  flavor 假设；
5.  CP 假设；
6.  输入参数方案；
7.  截断阶数；
8.  是否保留维数六平方项；
9.  数据能区或有效性切割；
10. 理论误差和协方差处理。

## 17.2 可复核计算链

**流程 17.2（计算链）.**

1.  写出 UV 或高尺度 Wilson 系数。
2.  在匹配尺度给出 $C_i(\Lambda)$。
3.  用 RGE 运行到实验尺度。
4.  转到破缺相并选择输入参数方案。
5.  计算振幅或截面。
6.  线性化或保留平方项。
7.  与数据协方差比较。
8.  报告有效性检查。

**原则 17.3.** 如果中间任一步省略，则最终结论应降级为“估计”或“投影”，不得称为完整 SMEFT 约束。

## 17.3 最小表格格式

正式结果至少应包含如下表格。

| 字段 | 示例 | 缺失后果 |
| --- | --- | --- |
| EFT | SMEFT dimension-six | 不知道自由度和对称性 |
| 基 | Warsaw | Wilson 坐标不可解释 |
| 尺度 | $1\ {\rm TeV}$ | 无法比较 RGE 后结果 |
| flavor | diagonal nonuniversal | 参数数不明确 |
| CP | CP-even | 是否含 EDM 方向不明确 |
| 输入方案 | $\{\alpha,G_F,m_Z\}$ | 电弱预测不可复现 |
| 截断 | linear dim-6 | 维数六平方和维数八边界不清 |
| 数据 | bins and covariance | likelihood 不可复现 |
| 有效性 | $m_{\ell\ell}<\Lambda$ | 高能 bin 可能越界 |
| 工具 | version/hash | 数值结果不可追踪 |

## 17.4 常见错误

**错误 17.4（混合基）。** 从一个基读取 Wilson 系数，却用另一个基的 Feynman 规则计算。

**错误 17.5（隐含 flavor 假设）。** 报告“$C_{\ell q}$ 的限制”而不说明 flavor 指标组合。

**错误 17.6（过度使用高能 bin）。** 使用 $E\sim\Lambda$ 或 $E>\Lambda$ 的数据，却仍宣称截断 EFT 结果模型无关。

**错误 17.7（维数六平方项误读）。** 保留 $C_iC_j/\Lambda^4$ 项，却声称结果是完整到 $1/\Lambda^4$。

**错误 17.8（把单系数图当作模型无关结论）。** 单系数限制是在其他 Wilson 系数固定为零的切片上得到的结果。若 UV 模型同时产生多个系数，该限制不能直接套用。

**错误 17.9（省略协方差）。** 多个 bins 或多个观测量共用系统误差时，忽略协方差会改变 Fisher 矩阵和 flat directions。

## 17.5 可复核性等级

| 等级 | 内容 |
| --- | --- |
| Level 0 | 只给文字结论或图 |
| Level 1 | 给 Wilson 限制和基本假设 |
| Level 2 | 给响应矩阵或 likelihood |
| Level 3 | 给数据、协方差、代码版本和有效性切割 |
| Level 4 | 给完整复现脚本和随机扫描配置 |

**原则 17.10.** 教材中的 worked example 至少应达到 Level 2；研究论文若给出数值限制，应尽量达到 Level 3 或 Level 4。

## 本章小结

SMEFT 的严谨性不只在公式，还在报告元数据。没有基、尺度、flavor、输入方案和截断说明的 Wilson 系数限制不可复核。
