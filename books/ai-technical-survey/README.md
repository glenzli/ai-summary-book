# 人工智能技术演进综述 (AI Technical Survey)

**署名作者：Dr. Stochastic Parrot**

这是一本关于人工智能（AI）发展与前沿技术的开源综述。本书梳理从符号主义、感知机、深度学习、Transformer、预训练语言模型、后训练，到多模态、Agent 与世界模型的技术脉络。

## 读者导言

本书面向希望系统理解现代 AI 技术演进的读者：可以是工程师、研究生、技术管理者，也可以是已经用过大模型但希望补齐机制背景的学习者。正文以概念、历史脉络、核心架构和训练范式为主；公式用于解释机制，附录提供可选的数学补充。

适合的阅读方式是：先顺序阅读导论与六章正文，建立从符号主义、神经网络、Transformer、预训练、对齐到多模态、Agent 基础与 Agent 系统工程的整体框架；遇到反向传播、优化、正则化、注意力或偏好优化等细节时，再回到附录查阅推导。
