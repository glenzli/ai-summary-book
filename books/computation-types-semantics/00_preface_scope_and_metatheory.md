# 第 0 章：范围、对象层级与证明状态

程序语言理论中最常见的错误不是某个符号写错，而是把不同层级的对象看成同一种东西：把程序文本当作函数，把类型判断当作运行事实，把规格证明当作自动验证器。本章先建立这些层级之间的边界。后续每章都在这个边界内移动，而不是靠隐喻把三种语义混成一个词。

## 0.1 三个层级

**定义 0.1（对象语言与元语言）。** 本书称被研究的程序、类型和证明项所在语言为**对象语言**；用于描述对象语言语法、归约、类型规则和语义模型的数学语言为**元语言**。例如，项
$(\lambda x.x)\,y$ 是对象语言项；断言“该项一步 β 归约到 $y$”是元语言命题。

**定义 0.2（语法、计算和语义）。** 对一个程序片段 $e$，本书区分三种对象：

1. 语法对象：有限树或有限字串，记为 $e$ 或 $\ulcorner e\urcorner$；
2. 计算过程：归约序列、机器轨迹或状态变换，记为 $e\to e'$、$e\Downarrow v$ 或 $\langle c,\sigma\rangle\to\langle c',\sigma'\rangle$；
3. 语义对象：集合函数、偏函数、cpo 元素、断言变换或关系，记为 $\llbracket e\rrbracket$。

这些对象之间可以由定理连接，但不是定义上相同。

**例 0.3（同一个 while 程序的三种读法）。** 命令
`while x > 0 do x := x - 1`
作为语法对象是一棵树；作为操作对象是一串状态转移；作为指称对象是从初始状态到最终状态的偏函数，其中当 $x$ 初始为自然数时终止并把 $x$ 变成 $0$。若状态允许负整数且条件仍为 `x > 0`，该程序也终止；若循环体改为 `x := x + 1`，指称对象对正初值未定义。类型系统只能说明赋值表达式形状合法，不能单独推出终止。

## 0.2 判断和定理的状态

**定义 0.4（判断）。** 判断是元语言中的形式断言。常见判断包括：

- $\Gamma\vdash e:A$：类型判断；
- $e\to e'$：一步计算判断；
- $\models \{P\}c\{Q\}$：Hoare 三元组语义有效；
- $\vdash_H \{P\}c\{Q\}$：Hoare 系统可证明。

判断不是布尔表达式的简写；每个判断由推导规则、语义解释或二者共同规定。

**定义 0.5（证明状态）。** 本书每个非平凡结论处于以下状态之一：

1. **内部证明**：正文给出完整证明，并穷尽相关规则或构造子的情形；
2. **外部输入**：固定对象系统、假设和结论，只使用精确陈述而不在书内重证；
3. **边界说明**：反例、限制或非定理性说明。

提纲性论证是写作过程中的中间物，不是上述终态。“证明路线”只能跟随外部输入，用来解释参考文献中的方法，不能被后文引用为已证事实。

后续定理不能把“边界说明”当作引理使用；使用外部输入时必须标明编号。

**定理 T0.1（对象层级的非自动传递原则）。** 在只给定定义 0.1--0.4
所述语法、操作关系和语义解释，而未加入连接公理的语言包类中，下列蕴含都不是普遍有效式：

1. 语法良构推出终止；
2. 终止推出满足任意另行指定的语义规格；
3. 语法良构推出满足任意另行指定的语义规格。

**证明。** 命令 `while true do skip` 由命令语法生成却没有终止大步推导，否定第 1 条普遍式。
命令 `x := 1` 终止于满足 $x=1$ 的状态，但不满足后置规格 $x=0$，否定第 2 条。
同一赋值命令语法良构而不满足该后置规格，也否定第 3 条。三个反例只证明所列前向蕴含无效；
本定理不声称反向关系在每种语言中都无效。类型安全、操作/指称一致性或 Hoare soundness
必须由后续专门定理在其明确假设下建立。证毕。

## 0.3 本书的闭合方式

本书不试图重建所有基础数学。集合、关系、偏序、归纳定义和推导规则模板集中在附录中。正文使用这些工具时给出明确调用；使用大型经典定理时标为外部输入。

**约定 0.2（语义模型的显式性）。** 每当出现 $\llbracket-\rrbracket$，必须能在同章或前章找到：

1. 解释对象的语法类别；
2. 目标语义域；
3. 自由变量或状态的处理；
4. 发散、错误或未定义的表示方式；
5. 与操作语义或证明系统的连接定理。

**例 0.6（错误的隐式语义）。** 句子“函数 $f$ 的程序语义是 $f$ 本身”不合格，因为它没有说明程序文本如何被映射到数学函数，也没有说明发散程序如何解释。合格写法是：在状态集合 $S$ 上，命令 $c$ 的指称为偏函数 $\llbracket c\rrbracket:S\rightharpoonup S$；若从 $\sigma$ 出发操作语义发散，则 $\llbracket c\rrbracket(\sigma)$ 未定义。

**例 0.7（同一命令的三个可核对判断）。** 令 $\sigma(x)=0$。赋值命令 $x:=x+1$ 可分别产生
$$
\Gamma\vdash x:=x+1\ \mathsf{cmd},\qquad
\langle x:=x+1,\sigma\rangle\to
\langle\mathsf{skip},\sigma[x\mapsto1]\rangle,
$$
以及
$$
\llbracket x:=x+1\rrbracket(\sigma)=\sigma[x\mapsto1].
$$
第一式是静态良构判断，第二式是一条操作轨迹，第三式是语义域中的函数等式。第 8 章 T8.3
证明后两式在完整命令语言中相容；它们不是同一个定义。
