# 凝聚数学讲义

作者：Dr. Stochastic Parrot  
状态：四卷完整草稿  
总题：从凝聚基础到 solid/analytic/liquid、复几何与计算例子

这是一套中文凝聚数学教材草稿。四卷现在统一放在本目录下，便于作为一套书维护。

## 分卷

1. [卷一：凝聚数学基础](volume-1/)  
   站点、sheaf、紧 Hausdorff/profinite 空间、凝聚集合、凝聚阿贝尔群、基本同调代数、solid 与 analytic 入口。

2. [卷二：Solid、Analytic 与 Liquid 结构](volume-2/)  
   solid 派生范畴、solid 环与模、解析环、解析化、liquid 向量空间、Huber pair、$f_!$ 和相干对偶入口。

3. [卷三：复几何与相干对偶](volume-3/)  
   复解析空间、相干层、Dolbeault、有限性、Serre 对偶、GAGA、Riemann-Roch 和六函子展望。

4. [卷四：形式化、计算与例子](volume-4/)  
   形式化路线、站点与 sheaf 计算、Ext/Tor 模板、solid/analytic/liquid 例子和 pro-etale 背景。

## 阅读建议

按卷一到卷四阅读。卷四也可作为工具卷，在阅读前三卷时随时查阅。

## 数学口径

本套书是严格教材草稿，不是原始论文替代品。能在书内证明的基础命题给出证明；Scholze、Clausen-Scholze、Gleason、Nöbeling、Cartan 等深层定理以输入定理或证明路线标注。

核心资料源分散记录在各卷的 `SOURCES.md` 中。
