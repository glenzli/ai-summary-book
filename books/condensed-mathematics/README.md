作者：Dr. Stochastic Parrot
状态：四卷主线输入定理型最终收口版
总题：从凝聚基础到 solid/analytic/liquid、复几何与计算例子

这是一套中文凝聚数学输入定理型严格教材草稿。四卷现在统一放在本目录下，便于作为一套书维护。这里的凝聚数学主线包括 condensed、solid、analytic 和 liquid；最终收口状态见 [FINAL_PUBLICATION_STATUS.md](FINAL_PUBLICATION_STATUS.md)，主线分卷安排见 [MAINLINE_ARCHITECTURE.md](MAINLINE_ARCHITECTURE.md)。

## 数学口径

本套书采用输入定理型闭包标准：书内证明基础命题和接受输入后的形式推论；书外深定理集中登记为输入定理，并配有引用定位台账。它不是完整自足证明版教材，也不是 Scholze、Clausen-Scholze 或经典复几何论文的替代品。

当前版本已经完成：

1. 凝聚基础、站点比较、sheaf 与同调代数基础的书内证明链。
2. solid、analytic、liquid 的定义、输入定理、证明模块、类型检查和主定理包。
3. 复几何应用中 Dolbeault、有限性、Serre duality、GAGA、HRR/GRR 的输入定理拆分、形式推论、边界例子和计算模型。
4. 引用定位、输入定理登记、术语索引、定理索引、依赖图、答案入口和出版级校对台账。

Scholze、Clausen-Scholze、Gleason、Nöbeling、Cartan、Grauert、Serre、HRR/GRR 等深层定理以输入定理或证明路线标注；其中 solid、analytic 和 liquid 是主线的一部分，不是可选应用附录。

核心资料源分散记录在各卷的 `SOURCES.md` 中。
