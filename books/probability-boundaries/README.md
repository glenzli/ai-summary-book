## 确定性机器、随机训练与不确定的观察者

**作者：Dr. Stochastic Parrot**

这是一部讨论“概率究竟出现在哪里”的中文教材。它从测度论概率出发，逐层区分随机变量、统计模型、采样算法、伪随机实现、因果干预、预测校准与观察者的信息不足，最后把这些区别用于语言模型。核心问题不是“机器是否随机”，而是：在一个具体陈述里，随机对象是什么，概率测度定义在哪里，谁不知道什么，以及固定哪些数据后计算仍有多少自由度。

本书不是反概率论。相反，它要求概率语言承担足够精确的数学责任。训练目标可以是统计的，参数可以由随机优化得到，解码可以调用随机源，硬件执行也可能不可复现；但这些事实彼此不同，也都不能自动推出“系统期待”“模型犹豫”或“一句话随机发生”。

构成后续章节的共同语言。第六、七章发展预测与决策，第八、九章分别处理执行和因果，

## 预备知识

读者应熟悉实分析中的极限、级数和 Riemann 积分，线性代数中的向量空间与内积，以及集合与函数的基本语言。第一、二章补足本书所需的测度论接口，但不重新证明 Caratheodory 扩张定理与 Lebesgue 积分的全部构造。
