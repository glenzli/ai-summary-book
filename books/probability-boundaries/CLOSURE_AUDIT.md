# 内容闭合审计

## 审计口径

本审计检查教材正文是否形成可在线阅读的闭合主线，不声称完成同行评审或形式化验证。

| 检查项 | 状态 | 说明 |
|---|---|---|
| 概率对象先定义后使用 | 闭合 | 概率空间、随机变量、核、条件期望均有类型声明 |
| 主线定理证明责任 | 闭合 | 见 `THEOREM_LEDGER.md`；大型结果明确标为外部输入 |
| 边界情形 | 闭合 | 零概率条件、无限期望、无密度、零温极限与并列最大值均有说明 |
| 数学随机与实现随机分离 | 闭合 | 第 8、10 章给出状态机与解码接口 |
| 观察与因果分离 | 闭合 | 第 9 章含结构反例与识别边界 |
| 心理词汇不由概率直接推出 | 闭合 | 第 11 章给出桥梁前提检查 |
| 练习与解答 | 闭合 | 所有编号练习在 `SOLUTIONS.md` 中有对应条目 |
| 外部来源 | 闭合 | `SOURCES.md` 列出一手或标准资料，正文说明用途 |
| Markdown/LaTeX 结构 | 由验证器检查 | 运行 `validate.py` 与全仓结构审计 |

## 第二轮严格复核记录（2026-07-14）

本轮依照 `../OET_RIGOR_STANDARD.md` 逐章复核定义域、量词、可测性、定理前提、证明闭环、反例、习题答案、引用边界与 LaTeX。复核限于既定内容范围，不以增加新主题代替证明责任。

| 重点项 | 结论 | 收口依据 |
|---|---|---|
| 完备化 | 闭合 | 第 1 章显式处理完成后任意零事件 $E=A\cup N$：若 $\overline{\mathbb P}(E)=\mathbb P(A)=0$，则 $E$ 包含于原 $\mathcal F$ 中的零集 $A\cup N_0$，故每个 $H\subseteq E$ 均属于完成 $\sigma$-代数且 $\overline{\mathbb P}(H)=0$ |
| 条件期望与正则条件分布 | 闭合 | 第 4 章补足诱导符号测度的可数可加性与有限全变差；正则条件分布只要求被条件化变量的值域为 standard Borel，并注明版本唯一性的共同零集 |
| 零概率条件 | 闭合 | 比值定义严格限于 $\mathbb P(B)>0$；当 $\mathbb P(B)=0$ 时分子也为零，故只出现未定义的 $0/0$，不把正则条件分布版本误称为唯一点值 |
| 评分规则 | 闭合 | 第 6 章固定损失方向、扩展实值约定与单纯形边界；对数损失及严格适当性的等号条件均覆盖零坐标 |
| 随机化引理 | 闭合 | 第 8 章明确输入可为任意可测空间、输出须为 standard Borel，并区分含不终止状态的推前概率与输出空间上的次概率 |
| 因果识别 | 闭合 | 第 9 章区分一般 SCM 与 Markov 核分解，给出相关外生变量反例，并证明观察分布及截断乘积分布的归一化和边缘公式 |
| 练习解答 | 闭合 | `SOLUTIONS.md` 覆盖 64 道练习；逐项核对零概率条件、数值例、干预量与条件核表述 |
| 引用边界 | 闭合 | `SOURCES.md` 与 `THEOREM_LEDGER.md` 为 Radon--Nikodym、$\pi$-$\lambda$ 唯一性、正则条件分布、Ionescu--Tulcea、随机化引理和数据处理不等式标明输入位置与适用范围 |
| 精确署名 | 闭合 | `validate.py` 要求 `README.md` 原样包含 `**作者：Dr. Stochastic Parrot**` |

本轮收口命令为：

## 有意保留在书外的内容

本书不展开随机过程、鞅收敛、随机微分方程、经验过程、随机矩阵、算法随机性理论和完整贝叶斯非参数理论。它们不是论证缺口，而是范围边界。若后文使用这些领域的结论，必须新增精确外部输入，不得以本审计替代来源。
