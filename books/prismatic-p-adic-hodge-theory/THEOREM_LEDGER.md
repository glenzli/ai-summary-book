# 定理账本

本文档按“内部证明”“外部输入”“研究边界”分类记录本书正式教材扩展稿中的正式数学陈述。它不新增数学定理。

- 第一章：$\delta$-恒等式推出 $\phi_A$ 为环同态。
- 第一章：$p$-torsionfree 环上 Frobenius lift 等价于 $\delta$-结构。
- 第一章：distinguished element 生成的 oriented prism 的 $p\in(d,\phi(d))$ 检查。
- 第二章命题 2.5、2.6：prism morphism 的 Frobenius compatibility 与 distinguished principal prism criterion。
- 第二章命题 2.19、2.21：cohomological Frobenius 的 semilinear/linearized typing，以及 affine probe 的 quotient 读法。
- 第三章形式推论 3.6、3.14 与命题 3.17：有限 Hodge--Tate filtration 保 perfectness、perfect completed base change，以及 comparison-map type separation。
- 第五章定义 5.4、形式推论 5.11 与命题 5.16：chain-level
  $\eta_f$ 的 cohomology formula、prismatic reinterpretation 的形式组合，
  以及 ordinary Tor-dimension one 的 cohomology base-change 短正合列。
- 第六章命题 6.16：finite locally free crystals 的 tensor/dual 以及 localized Frobenius compatibility。
- 第七章：naive Nygaard filtration 的递减性和张量乘法相容。
- 第九章：Hodge--Tate associated graded 推出 perfectness 和 finite generation 的形式推论。
- 第十章：crystalline prism 的 boundedness。
- 第十一章命题 11.5、11.11--11.13：degree-zero fixed fibre、multiplicative comparison 的形式后果、长正合列与 acyclicity criterion。
- 第十二章命题 12.6、12.15：Breuil--Kisin module 局部化后的 Frobenius module 及 rank-one height computation。
- 第十三章：带系数 cohomology 在 $\mathcal E=\mathcal O_\Delta$ 时回到普通 prismatic cohomology。
- 第十五章：基础定义链闭合判定。
- 附录 A 命题 A.4、A.5、A.8、A.14：regular principal Koszul model、bounded-torsion completion criterion、torsionfree implies bounded torsion、complete flatness implies flat reduction。
- 附录 G：derived global sections 保 quasi-isomorphism。
- 附录 H：$\delta$-环恒等式、distinguished element 和 boundedness 的逐项证明。
- 附录 I：crystal base change 保 finite projective，rationalization 不决定 integral lattice。

- 第十三章：free coefficient crystal 的 cohomology 计算。

## 外部输入定理

- `BS-DCOMP`：Koszul derived completion、complete flatness 与 finite complete Tor-amplitude 的一般形式。
- `BS-PRISM-DEF`、`BS-PRISM-SITE`：prism/bounded prism、ideal rigidity 与 relative prismatic site/topology。
- `BS-PERF`：perfect prisms 与 perfectoid rings 的等价。
- `BS-COMP-HT`、`BS-COMP-DR`、`BS-COMP-CRYS`、`BS-COMP-ETALE`、`BS-COMP-BC`、`BS-COMP-PHI`：分别对应 Hodge--Tate、completed Frobenius-twisted de Rham、derived $p$-complete crystalline、finite-level etale、completed base change 与 after-$I$ Frobenius isogeny。
- `BS-COMP-AINF`、`BMS1-AINF`：$A_{\inf}$ comparison 的 Frobenius pullback 与 BMS 四个 derived specializations。
- `BS-COMP-BK`、`BMS2-BK`、`BMS2-BKLOCAL`：Breuil--Kisin/prismatic comparison、global cohomology complex 与 local THH construction。
- `BMS1-BKF`：BKF definition、finite-free Fargues classification 及 cohomological torsion thresholds。
- `BMS2-SYN`：syntomic fibre/products 以及 characteristic-$p$/mixed-characteristic nearby-cycle comparisons。
- Fontaine/Faltings/Tsuji classical $p$-adic comparison theorem。
- Fontaine theory 中 $B$-admissibility 的 dimension criterion 和 weak admissibility 相关线性代数判据。
- `BS-FCRYS`、`BS-FCRYS-BK`：prismatic $F$-crystals 与 crystalline $G_K$-lattices 的范畴等价，以及 Breuil--Kisin evaluation/descent boundary。
- Bhatt-Lurie prismatization 中 prismatic crystals 的 quasicoherent sheaf 解释。
- Hodge-Tate/de Rham refined filtration comparison。
- Crystalline-de Rham-Witt and $q$-de Rham comparison。
- Etale comparison 的 derived Frobenius fixed-point reformulation；只有 finite-level theorem 本身作为外部输入，书内 fibre 计算属于形式推论。
- Breuil--Kisin and Breuil--Kisin--Fargues module outputs from integral cohomology；finite projectivity、effectivity 或 height 均不自动附带。
