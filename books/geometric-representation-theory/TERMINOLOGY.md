# 术语压缩表

本文件给出正文中应优先使用的短术语。目标是减少同一概念的多译名漂移。

## 1. 基本原则

1. 有稳定国际用法的术语保留英文，如 `perverse sheaf`、`D-module`、`category O`。
2. 中文解释只在首次出现或教学说明中使用。
3. 同一章内不交替使用多个译名。
4. 表格中的“不再使用”不是数学错误，只是为统一阅读体验而压缩。

## 3. 缩写规则

1. 首次出现写全称：Khovanov-Lauda-Rouquier algebra。
2. 后文使用缩写：KLR algebra。
3. 对同一对象的符号优先于文字重复，例如用 $\operatorname{Gr}_G$ 代替反复写 affine Grassmannian。
4. `GLanglands` 不作为正文术语使用；正文统一写 geometric Langlands。

## 4. 后续替换策略

若要进一步机械统一正文，可按下列优先级替换：

1. `O 范畴` → `category $\mathcal O$`；
2. `D 模`、`微分模` → `D-module`；
3. `仿射旗簇` → `affine flag variety`；
4. `几何 Satake` → `geometric Satake`；
5. `定理定位` → `theorem locator`。
