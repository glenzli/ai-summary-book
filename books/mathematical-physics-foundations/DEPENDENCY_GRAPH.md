# 章节依赖图

本书依赖关系按“最小必要前置”记录。箭头 $A\to B$ 表示阅读 $B$ 前应掌握 $A$ 的对象或结论。

## 主线

```text
00 -> 01 -> 02 -> 07 -> 08 -> 09 -> 10
      |     |           ^           ^
      |     v           |           |
      -> 03 -> 06 ------+           |

      04 ---------------------------+
      |
      v
      A

05 -> 06 -> 09
05 -> 08
A  -> 01,05
B  -> 04,10
C  -> all chapters as formula reference
```

## 逐章依赖

| 章节 | 直接依赖 | 输出对象 |

| 02 | 01 | 辛形式、Poisson 括号、moment map |

| 04 | 01,03,B | 主丛、联络、曲率、Chern-Weil |

| 06 | 02,03,05 | Hilbert 空间量子力学、对称性、自旋 |

| 08 | 05,07 | 路径积分、有效作用、重整化推导 |

## 外部输入边界

- `01-04` 以有限维微分几何为主，除 Darboux、de Rham、Chern-Weil 拓扑同一性外可在书内闭合。
- `05-06` 依赖无界算符和谱理论外部输入，正文只证明有限维或有界模型版本。
- `08-10` 的路径积分、重整化、BRST 完整性、异常公式以标准物理推导说明为主；严格构造或非微扰存在性不作为正文结论。
