# 附录 G：正式教材化审查标准

## 状态

本书当前为教材内容与阅读排版收口稿。已从初版草稿扩展为含关键非相对论模型、现代测量接口、基础定理、外部输入依赖图、逐章来源注释、统一阅读索引、压缩术语表、提示手册和答案手册的教材内容闭包。

## 必检项目

- [x] 每章有目标、前置知识、小结和练习。
- [x] 所有章末练习和综合题有提示手册条目。
- [x] 所有章末练习有答案手册条目。
- [x] 所有综合题有答案。
- [x] 无界算子相关结论区分内部核心计算与外部输入定理。
- [x] Born 规则、Luders 更新、POVM、Kraus 仪器和密度态口径区分。
- [x] 核心模型包含方势阱、谐振子、角动量、自旋、中心势、氢原子、电磁耦合和 Landau 能级。
- [x] 基础定理包含 Robertson 不确定性关系、概率流连续性方程、Ehrenfest 定理、Dyson 展开和角动量耦合。
- [x] 精算例题包含 Gaussian 波包扩散、自旋进动和 Rabi 振荡。
- [x] 内部证明闭包与外部输入闭包已有矩阵化审查文件。
- [x] 外部输入定理在依赖图与索引中可追踪。
- [x] 统一阅读索引、术语索引、提示入口和答案入口已经接入主目录。
- [x] 内容收口审查已由 `H_content_closure_audit.md` 固定。

- 将 Markdown 正文转为统一 LaTeX 或 PDF 版式。
- 扩充章内例题编号、页码索引和正式排印索引。
- 对所有外部资料源补正式书目信息。
- 若目标是研究生级正式出版稿，应增加每章 10--20 道练习和更多长证明。
